## 可见制作与原生结构

通过 Windows COM 调用 ExtendScript，在 Illustrator 内直接创建路径与文本。没有先插入整图再显示/隐藏，没有用图像描摹、参考背景或整页 SVG 替代重建。

主绘制实际创建 1,173 个场景对象，约 77.18 秒，每两个场景对象刷新一次窗口，附可调延迟。实际 [创建顺序](.build/lis-visible-r1.drawing.jsonl) 与 [原生回读摘要](.build/lis-visible-r1.render.json) 均保留。之后在可见窗口修正 4 个标题和电子标注的位置，[改动记录](.build/alignment-repair.json) 单独保存。

最终文件结构如下，避免把容器和子轮廓重复相加：

| 项目 | 实际数量 |
| --- | ---: |
| 画板 / 图层 | 1 / 6 |
| 非容器叶对象 | 1,219 |
| 普通 PathItem 叶对象 | 1,178 |

## 发现的问题和修复

1. **化学式缺字**：第一小样中 Unicode 下标显示方框，字面内容检查却通过。改用普通数字及原生下标属性；`⇌` 明确指定 CambriaMath。保留 40 个可编辑文本对象，并回读字符范围，不把成品文字描边。
2. **文字框与实际字形不一致**：混合字体/下标的原生框远大于字形。改为临时复制文本、描边测量字形、删除临时副本；原文本保留。最终核对容纳和位置，而非只检查字符串。
3. **复合路径保存后的绕向**：负轮廓在重开后可能调整锚点顺序。检查改为比较闭合曲线的等价循环起点和绕向，同时核对左右控制柄；开放路径仍严格保留方向。原始失败结果保留在 `.build/probe-check-r2.audit.json`。
4. **左对齐标题被居中**：本机 ExtendScript 对未加括号的连续三元表达式未按预期分支。改用显式 `if/else`，可见重排 5 个文本，并新增字形位置检查。小样 `probe-r4` 和完整图最终检查通过。早期完整图的审计未检查位置，不能用它证明最终排版正确。
5. **复杂图检查速度**：原生对象反复按名遍历导致第一次检查约 148 秒。缓存当前已打开文档的对象名后，完整检查约 8 秒；重开不复用旧引用。几何、文字与移动检查范围未删减。

这些经验已写入 skill 参考和运行脚本。小样、早期失败、早期完整图和修正版均保存在 `.build/`，交付目录只保留最终结果。

## 视觉结果与使用限制

对照保留了原图的主要布局和科学关系，增加真正可编辑的复合开口、径向渐变和面板整体分组。与 PowerPoint 版相比，检验了不同的原生路径编辑能力；没有证明 Illustrator 在所有图型上更接近参考。

材质、连续泡沫形貌、纤维随机性、三维光照和颗粒排布仍为几何近似。不是逐像素 1:1 复现，未加入原子结构、精确孔径或性能数据。[像素诊断](comparison-final.json) 的整图 MAE 为 33.25/255、前景 MAE 为 57.07/255，3 px 容差暗像素召回 0.553、精确率 0.833；这不是还原百分比。与此前 PowerPoint 的对应诊断相比，并未显示整体像素误差明显改善。

Illustrator 的线与箭头是原生路径，**不具备 Visio/PowerPoint 式自动吸附与重连**。已验证面板内部整体移动，跨面板放大引线独立于组，移动面板后需重新调整；未验证自动避障、跨组重路由、网格、图案、剪切蒙版或其他 Illustrator 版本。
