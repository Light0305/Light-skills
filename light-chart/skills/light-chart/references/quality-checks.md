# 成图检查与交付

1. 数据：观测、类别、单位、配对和处理记录对应输入；没有未说明的排除/截断。
2. 统计：n 的单位、误差/区间、检验和校正来源清楚，不伪造未知信息。
3. 编码：图型/尺度适合比较，颜色/面积含义明确，缺失与变换可解释。
4. 文字：最终尺寸可读，无缺字、裁切、图例压数据或标签遮挡。
5. 多面板：实际绘图区/标签一致，跨图编码统一，特殊布局有依据。
6. 文件：物理尺寸、像素/DPI、可编辑文本及需要的 source data 可用。

论文输出另查：介绍性总标题/副标题/长脚注是否仍被写在图内；移出后是否还留着空带；图注是否独立且统计定义完整。表格默认是可 `\input` 的 `.tex` 与数值文件，不能用表格图片替代稿件原生表格。坐标、单位、必要图例和条件标签应保留。

`publication.py` / `.R` 组合自动检查。最终 PNG 和 PDF 渲染需实际读取；逐面板核对后更新 QA 的 `visual_review`，不能仅运行脚本即称视觉通过。

技术通过之后，实质重做的论文图按 [editorial-review.md](editorial-review.md) 检查层次、密度、参照差距和阅读成本，单独写 `design_review`。用户否定审美后保留前稿并实际改图；不能用文件通过率或测试数量证明审美。

## 程序状态

- `PASS`：已执行自动检查未发现问题，视觉审查需另行完成。
- `REVIEW_REQUIRED`：警告需看图裁决，例如有意色块内文字或栅格内容。
- `FAIL`：尺寸、缺字、可靠碰撞等失败，修复后重跑。
- `NOT_AUDITABLE`：缺依赖、解析失败或无可审查文本，记录实际限制。

有意叠加逐项说明，不统一忽略所有警告，不通过改阈值隐藏错误。PDF 字号扫描支持常见内容流，不能覆盖所有 Form XObject/字体变换；复杂外部 PDF 需额外看图或针对其结构检查。

修改源代码，重渲再看；变化后重做受影响检查。迭代达到上限保留最佳现有版本并说明余留问题，不伪称通过。交付代码、必要输入/映射、成图及简短实际结论；诊断可保存在输出目录供追溯。
