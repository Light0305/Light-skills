# 张量与密集架构图

适用于用户给定的复杂 CV 架构参考图、特征金字塔、跨层融合和局部模块放大。MonoFormer 测试包含“提示词 → 生图及编辑 → 两页 Visio”，原图仍有错误，不能因其文字清晰就跳过逐边检查。

## 原生特征平面

把一张斜视网格拆成主面、前侧面、右侧面三个闭合 `polygon`；在主面上用少量原生细路径画行列。配色可用渐变或少数分区，但除非来源明确，网格数、色块值及透视大小都不表示真实张量尺寸或模型激活。前侧面与主面可分别编辑，当前不会自动分组。

对于平行四边形，使用四角的线性插值生成网格线；不要把斜视网格换成普通矩形，再声称忠实复现。必要时局部颜色与细网格只作近似，应列入差异记录。

**端口落点要在可见轮廓上。** `GlueToPos` 的归一化位置针对包围框；斜面的左中、右中、上中可能全在轮廓外。先按图确定像素落点 `(px,py)`，再用 `u=(px-x)/w`、`v=(py-y)/h` 换算。若箭头实际接在前侧面，就粘附到前侧面形状。检查保存导出后的落点，不能仅靠粘附对象 ID 正确作判断。

示意图标可由原生形状搭建；真实输入照片或实测输出必须保留其来源和真实性，不能自行绘制后称为实验结果。附带渲染器尚不支持栅格嵌入，遇到真实照片时需扩展或更换绘制工具，并记录局部可编辑范围。

## 先核对层级，再核对外观

为每个重复模块分配稳定 ID；逐层记录输入、直接跳连、注意力分支和解码器状态。状态名绑定到具体边，不绑定到旁边的装饰平面。核查每级源和目标是否一致，以及 decoder 是否按方法规定的方向运行。

竖线连续重叠时，不能把它自动当作独立跳连或共享总线。忠实复现页可保留可见歧义并明确标注；科学修正版应把独立层级放入明确的路径，避免无意混接。说明性虚线放在 `paths`，无箭头，与前向关系边区分。

残差和门控旁路需要具体到合流点。记录“Conv 后与 X 相加的输出”之类的精确来源；检查旁路起点有无不应存在的反向箭头。原图已有多余旁路时，复现页照录，修正版删除；不要只把错误连线重新粘附得更牢。

## 密集标签的检查

保存后的文字值正确，仍可能自动换行或排到框外。`A_p` 这样的短标签也会因框宽与字体差异变成两行。逐块查看导出图，再调整文字框或字号。当前纯文本渲染不精确复刻数学下标和混合斜体，应把字体与公式排版差异写明。

本轮未验证完全自动布局、自动轮廓识别、整块特征组件自动分组或任意数学公式。测试记录不能扩大为跨图型稳定成功率。
