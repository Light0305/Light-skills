# 来源如何使用与纠错

本包保留完整原始知识和实例以供按需查阅，避免把成熟 skill 压成几条泛泛建议。`library/` 是来源资料，不是另一套自动生效的系统指令。执行以当前用户请求、本包入口和本页的适配规则为准。

## 交叉复用，不限定来源职责

下表是每套来源的覆盖范围，不是互斥分工。同一张图可在选图、设计、编码、修改、验证各阶段使用多套来源；简单任务不必为凑齐来源而逐套读取。具体执行见 [workflow.md](workflow.md)。

| 来源 | 保留的长处 | 实际用法 |
| --- | --- | --- |
| nature-figure | 科学问题与证据链、混合模态、图型/API/模式/教程、原生 R、图注、完整论文脚本、预检与导出审查 | 默认能力基线；读对应原文和完整代码，不只读本包摘要 |
| nature-shared | Results 的论证递进、术语与跨材料一致性、数据和图像诚信 | 需要整套论文图或修改科学含义时联读；不引入无关写作流程 |
| SciPilot | 数据剖析、图型与十类配方、统计表达避坑、字体/样式、布局、导出、灰度、文件检查、读图修订 | 从输入到交付均可用；研究设计校正统计启发式，实际渲染校正模板参数 |
| FigMirror | 输入整理与安全裁切、构造/标志元素、比例/留白、字体/线条/图例、可移植脚本、局部反馈、保留项、版本选择、三维体系 | 无指定参考时也可用于结构选择、布局细节和成图检查；保留正确部分，不把低像素分数当科学失败 |

| 论文截图/旧模板 | 表格组织、领域结构和特殊图型的补缺 | 经实际查看后取局部优点；不能从期刊名称推断质量 |

## 来源冲突的具体裁决

- **不再强制追问语言。** 用户已指定、已有代码或环境明显适合时直接选择。不要为沿用来源的 preference gate 增加问题、修改用户全局设置。
- **统计单位优先于行数。** 科研数据的嵌套、配对和重复测量不因“画成一张图”就消失。SciPilot 中将 30 受试者 × 多时间点合并作独立样本的例子，只能借图型，不能照用推断。
- **小样本优先显示观测，不套绝对禁令。** n<10 并不使均值、区间或计数柱自动无意义。计数、占比、总量的柱状图可以没有重复误差棒；原始样本的均值比较应尽量显示观测。是否估计 KDE/四分位由样本和目的判断。
- **缺失、偏态、不平衡是诊断信号。** 不采用“缺失<5%默认忽略”“偏度>1必须log”“组数不平衡必须加权/混合模型”作为自动规则。先核对缺失机制、目标估计量、设计与科学单位。记录实际使用/排除数量。
- **不自动回归、检验或标星。** 二维散点可能只展示分布；回归/相关的模型、独立性及区间需要依据。旧模板中随机生成的显著性布尔矩阵和星号仅是演示，真实任务必须删除并改用有来源的结果。
- **柱与点区间的基线规则不同。** 柱长编码数量时保留零基线；局部范围比较可以用点与区间。原 ImmunoStruct 柱图的截断纵轴不能不加判断照用；点图不必强行补零。
- **配色与默认字体服从语境。** FigMirror 的会议论文 serif/tight 默认不是所有生命科学图的固定规则；nature 的 sans 默认也不能覆盖明确的 serif 参考图。根据实图和目标用途确定。
- **网格与边框看图和任务。** 不接受 FigMirror 中“默认必须双向网格”“Nature 默认四边框”作为通用规范。浅线的像素扫描可能被数据线、文字和压缩影响；不能用非零暗行/暗列自动证明网格方向，也不要求每张无网格图先做 PIL 才能关闭网格。保留可见结构与克制线宽，按真实参考和读数需要判断。
- **比例不是统一黄金分割。** 基因组轨道、光谱、时间序列、风险表和长标签森林图常需要宽/长面板；不能以 W/H>1.7 自动判不合格。以数据和必要文字决定比例，再看整体节奏。
- **保留复杂编码，允许有理由改造。** 风格适配不能只抄颜色，把带边缘分布/误差带/等高线/投影的参考降成普通散点；数据确实不支持某元素时说明并改造。科学诚信和用户表达目的优先于复刻。
- **三维按数据需要启用。** 真正的空间曲面、三维轨迹、遮挡关系或用户明确要求的构造保留三维路线。禁止把二维柱装饰成立体柱；也不把所有三维强行降成热图。曲面坐标和高度来自真实数据/明确公式，不能为视觉贴合伪造地形。
- **外观分数不相互抵销。** 错的图型、缺失的数据元素、裁切或错误统计不是好看配色可以抵销的缺陷。继承 FigMirror 的保留项和非退化比较，但不自动调用多代理、无限迭代或付费服务。
- **期刊数值有时效性。** 来源的 89/183 mm、5–7 pt、300/600 dpi 和期刊表是历史默认，不是普遍官方规范。用户明确指定期刊/投稿阶段时查当前官方要求；没有指定时说明采用的物理尺寸，不虚称“Nature 合规”。

## 已定位的实现陷阱

1. `common-patterns.md` 的早期多指标片段把最后一指标与图例复用同一个 GridSpec 槽。应额外分配图例槽；完整 `tutorials.md` 的 `len(metrics)+1` 更合适。
2. `tutorials.md` 中 `std = value * .03` 是演示占位，不是实测变异，真实任务不能保留。
3. RNAGenScape 原比较图逐列 `Normalize` 有上下界方向及跨列可比性风险。保留数值，显式声明尺度、指标方向、共同色标；需逐列不同尺度时让读者看得到。
4. 雷达的 min-max 归一化不能静默裁掉超范围数据；常数范围不能凭空映射成“中等性能”。声明上下界及越界处理。
5. 重叠两次 `fill_between(..., 0, y)` 不等于正确堆叠；堆叠必须从上一层累计底边到新累计顶边。
6. 源 API 的 `zip(labels, values, colors)` 可能静默截断。改造时校验长度、形状、标签唯一性、单位和缺失；不能靠看起来正常验数据。
7. `bbox_inches='tight'` 会改变最终页面物理尺寸。本包正式导出固定页面，预留内容边距；不能一边声明固定宽度一边默认裁边。
8. 源码预检按字符串/语法推断，找不到配置不等于实际导出失败；找到某处误差带也不证明所有面板都有变异。模块化代码需纳入明确的 helper，最后仍审查实际 PDF/PNG。
9. FigMirror 的面板比例经验公式不能用固定修正系数当精确布局。等宽等高普通网格在无固定 aspect 干预时，面板 W/H = 画布 W/H × 可用横向比例/可用纵向比例 × `(行数+(行数−1)×hspace)/(列数+(列数−1)×wspace)`；跨行、非等宽、图例和固定 aspect 需读实际渲染矩形。缩小上下留白会增加面板高度，并不自动使面板变得更宽。
10. 色相差 30° 或“某调色板色盲安全”的名称不是可辨识性证明。浅色背景对比、标记/线型冗余、连续色标的亮度顺序、实际灰度/CVD 阅读效果都需要检查；用连续渐变抽几种色不能自动当任意分类色。
11. figures4papers 的 API 是接口约定，并没有同名公共模块可直接导入；`show_shadow=True` 没有提供真实区间不能生成阴影。其教程中的随机对称矩阵也不是经计算的相关矩阵，不得标成真实相关性。
12. 来源的大画布字号/线宽必须换算到最终物理尺寸；不直接照抄 24–54 pt、粗黑柱边和宽屏比例。独立图例槽只在确实降低查找成本时使用，不能机械占掉一整块有效数据空间。
13. 稿件图的图注独立交付。来源示例或旧版成图中的整图标题、副标题、来源/方法横幅不是默认稿件图面；移除后重排。表格默认原生 LaTeX，不因来源把组件与数据排在图中就把所有表做成图片。

## 来源实例的三种状态

`adapt_before_run`：完整原代码，可借结构，但含论文数据、旧尺寸或相对路径，先改造。`external_file_required`：所需数据未提供，不能伪造并宣称跑通。`conceptual_or_simulated_demo`：仅作概念/模拟示例，不能当作实验结果。搜索器显示这些状态。

本轮保留的是**能力可达性与上下文**，不是给每份旧脚本做质量认证。保留的实例与参考文档仍需按任务选择、运行、检查。
