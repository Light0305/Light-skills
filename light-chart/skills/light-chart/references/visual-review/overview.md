# 视觉审阅的输入与边界

本目录是 Light-Science 自行编写的审图指南，配合 `scripts/review_cycle.py` 和 `review_engine.py`。审阅对象是一份确定的导出文件；数据和分析的正确性另行核对。

从任务中选需要的资料：排版读 layout-and-type；参考图读 comparison；修订读 repair-and-preservation；三维从 three-d/route 进入。不要一次加载整套资料。

开始前明确研究问题、显示编码、最终物理尺寸、参考图的角色和不允许改变的科学含义。结束时保留采用版本、真实意见、修改理由与未决问题。文件校验通过只说明输入和记录一致。
