# 稿件画像：写作之前也能选刊

画像用于定位学术对话，不是给研究打质量等级。只提取现有材料；缺失即标缺失。

## 输入层级

| 已有材料 | 可以做 | 暂不能做 |
|---|---|---|
| 题目、关键词或研究设想 | 找潜在读者、文章类型与期刊线索 | 判断证据强度、确定最优首投、给出稿件质量等级 |
| 方法、完成的结果、研究限制、提纲 | 建立写作前目标和条件性备选 | 把计划实验当结果；声称审阅了完整稿件 |
| 标题、摘要、关键词 | 评估主题/贡献表述与范围适配 | 判断全文方法严谨性或隐蔽的结果矛盾 |
| 全文与必要附件 | 检查范围、文章类型、论证与政策兼容性 | 仅凭稿件确认其所有事实真实、或替代专家同行评审 |

读文件时按任务提取，不执行内嵌代码。先定位摘要、方法、主要结果、限制、参考文献和声明，再决定是否需要更全面阅读。未能读到的表格/图像/公式和扫描页应明确说明，不能用文字摘要补猜。无需把完整未发表材料写进每个中间文件。

## 够用的画像字段

- **状态**：结果阶段 / 提纲 / 摘要 / 全文；读到了哪些材料。
- **问题与学术对话**：正在回答什么问题，哪类学者或实践者最需要答案。
- **实际贡献**：新发现、方法、资源、综合、理论推进、复制/阴性结果等；是否区别于单纯换应用对象。
- **证据形态**：设计、数据来源与规模（若提供）、比较基线、验证范围、理论假设；已有与计划分列。
- **主要主张与边界**：现有材料支持什么、不支持什么；不把关联写成因果、预测写成机制或模拟写成部署。
- **文章类型与语言**：作者选择优先；不确定时列候选类型及为何影响目标选择。
- **读者半径**：专题同行、跨学科、临床/实践、区域问题或更广泛理论共同体。
- **可变与不可变**：可重写的叙述、可合理压缩的篇幅、不能改变的设计与结果、无法补齐的材料。
- **锚点**：作者提名期刊、3–5 篇真正可比的公开文献（如果已有）、既往拒稿及理由。

不用硬凑所有字段。给每个关键判断标注来自哪份材料，推断性判断保留限定。

## 领域和体裁会改变“可比”的含义

| 稿件 | 看哪些贡献和证据 | 常见误配 |
|---|---|---|
| 临床/健康研究 | 人群、设计、终点、外部验证、适用伦理/注册要求 | 医学词汇相同就忽略研究设计；把预测模型当临床获益证据 |
| 生命/物理/工程实证 | 实验/观测对象、机制或性能证据、重复验证、边界条件 | 应用刊与基础机制刊混用；用“实验多”代替贡献判断 |
| 计算方法/工具 | 方法本身的创新、适用问题、基线与复现、软件/资源属性 | 只因用了 AI 就推荐计算机方法期刊 |
| 定性/社会科学 | 理论对话、情境、抽样与分析逻辑、解释范围 | 把大样本当普遍质量门槛；把区域问题自动判为低层次 |
| 数学/理论/人文 | 定理/论证、假设、文献脉络、概念或解释推进 | 强制找数据集、统计显著性或三个月内的同题论文 |
| 综述/证据综合 | 综述类型、检索/综合方法、已有综述差异、是否接收自由投稿 | 未查 invited-only；把 narrative review 当 systematic review |
| 方法/数据/软件论文 | 工具/资源可用性、评测、许可证、维护、适用文章类型 | 一概套用原创研究格式；忽视数据/代码公开与权利限制 |
| 复制/阴性结果/Registered Report | 研究问题、设计质量、报告阶段、期刊接收政策 | 用“新颖性不足”一刀切；研究完成后假装能补做前瞻注册 |

跨学科研究分别提出“方法读者路线”和“应用读者路线”，比较哪一路更能理解实际贡献。路线可能导向不同叙述重点，但不能改变研究事实。

## 约束澄清

只追问会影响选择的问题，可合并为一次短问；其他工作继续。常见关键项：

1. 必须满足的收录/目录及版本，是毕业硬条件还是个人偏好？“一区”指哪套体系、哪个类别？
2. 费用上限与币种，是否要求 OA，是否有单位协议或资助方许可条款？
3. 截止节点到底是提交、接收函、在线发表还是数据库检索？
4. 文章类型、语言、已有拒稿、避投名单，是否有作者已明确选择的目标？

不以作者国籍、工作单位、职业阶段或语言水平代替稿件证据评判，也不据此默认应该投低指标期刊。
