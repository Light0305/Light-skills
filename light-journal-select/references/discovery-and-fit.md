# 候选发现与稿件—期刊匹配

## 召回路线

从多种证据找候选，而不是先按指标给稿件定档。

候选按期刊实体去重，结合正式刊名、ISSN/eISSN、出版者和更名沿革归并同刊不同写法；不要把名称相近的子刊合并。会议和预印本可以帮助发现学术共同体，但本skill的最终投稿目标是期刊，不自动混入会议。

| 路线 | 做法 | 局限 |
|---|---|---|
| 作者/导师提名 | 先查作者真正考虑的期刊；保留作者约束 | 权威建议仍需核查当前范围与条件 |
| 参考文献邻域 | 看直接方法/问题文献在哪些刊发表，再找近期邻近作品 | 引用频次偏向大刊、老刊和经典文献；不是投稿义务 |
| 独立主题检索 | 用问题+方法、问题+贡献、替代术语寻找实际论文及其期刊 | 数据库不覆盖不等于期刊不适合 |
| 官方范围与类型 | 根据问题、证据形态和读者查官方 scope 与类型 | 宽泛 scope 不等于编辑愿意接收所有主题 |
| 领域/地区目录 | 根据目标语言和学术共同体查学会、学科目录、地区平台 | 目录收录、评价分区与实际适配是不同层面 |
| 推荐器 | 若已有授权，使用跨出版商工具，或对照多个出版商工具 | 限定候选宇宙、商业偏向、语义偏差、保密和条款问题 |

可用稿件主题和公开文献做研究检索，无需先把未发表摘要上传到推荐器。没有现成网络工具时按环境已有工具查找；不凭空要求某个工具名，也不自动安装付费服务或调用外部 LLM。

检索示意（替换为通用、不敏感术语）：

```text
"<研究问题>" "<证据/方法>" journal
"<贡献类别>" "<学科>" recent research
"<正式刊名>" aims scope
"<正式刊名>" "<article type>" author instructions
```

生物医学可用 PubMed；跨学科可用 Crossref、OpenAlex、学术搜索和出版社档案；计算/数学还可用 DBLP、领域索引和正式发表记录；社科人文、中文及地区研究结合相关领域目录与官方期刊网站。预印本可以找学术共同体，不能伪装为某刊已发表的内容先例。API、访问限制和授权随时间变化，以当前文档与实际返回为准。

## 召回偏差检查

- 是否只查到一个出版商、语言或数据库？增加一次独立路线，或说明领域集中/可访问性限制，不强制凑出版商数量。
- 高频应用词是否盖过实际贡献？例如公共政策中的疫苗舆情不自动适合临床疫苗期刊。
- 是否把大刊论文数量多当作匹配更好？比较代表性研究，避免用裸篇数定适配程度。
- 是否错过独立学会、小型专题刊、diamond OA 或区域/非英语学术共同体？按稿件目标补查，不把缺 JIF 当不合法。
- 是期刊常规内容，还是一次特刊的例外？特刊有无当前开放征稿、适用文章类型和截止日期？特刊不能覆盖母刊硬政策。

## 按刊建立匹配证据

先列稿件的 2–4 个决定性要素，再查每刊是否承接这些要素。不要在看到期刊后反向发明稿件优势。

| 维度 | 支持适配的证据 | 反证/不确定性 |
|---|---|---|
| 问题与范围 | 官方 scope 明确覆盖主要问题与研究对象 | 官方排除某类研究；只覆盖稿件的次要应用 |
| 贡献形态 | 接收该类方法、理论、资源、综合或实证贡献 | 只接受特定文类；综述需邀请；只欢迎临床研究 |
| 方法与证据 | 同类研究以相近设计回答相近问题 | 所选样本全是多中心前瞻研究，而本稿仅单中心回顾数据；只能解释差异，不能发明硬门槛 |
| 读者与意义 | 目标读者能使用研究结果，问题对其有意义 | 叙述依赖其他领域背景；目标刊读者只关心次要部分 |
| 新颖性/增量 | 说明与刊内已有工作的具体增量 | 与已发表内容过度重叠；新颖性未核实 |

“期刊要求多中心”“至少 N 个样本”“必须机制验证”只有官方明确要求时才作为硬条件。从样本论文看到的趋势只写成观察，不上升为政策。

## 可比论文卡

每篇保留：题名、期刊身份、年份/日期、DOI或稳定链接、核实来源、匹配维度、重要差异。全文未读时不要描述摘要之外的细节。

优先匹配**主要问题 + 贡献类型/证据形态**；方法或对象相近但学术问题不同，可以作弱证据，注明原因。避免只挑看起来支持推荐的论文；如有明显不同的典型内容也应反映。

默认最近 2–3 年，每个重点候选约 2–3 篇；快速比较可更少，专题/理论/低频领域可延长到 5 年或更早。记录实际查询和日期范围。只检查到一篇就只报一篇，别暗示它代表整刊。

没有匹配时依次区分：

1. 检索失败、权限或数据库覆盖不足；
2. 文章类型、关键词或更名问题；
3. 内容稀疏/新主题/新刊；
4. 实质范围不匹配。

可换同义词、延长一次窗口或查官网档案。收益很低时停止，列明缺口；不要无休止扩大检索，也不把一次空结果当负面事实。

## 结论表达

**适配程度**：强匹配 / 有条件匹配 / 弱匹配 / 尚不能判断。

**证据信心**：高 / 中 / 低，并说明是身份、官方政策、可比论文、稿件完整度还是约束待核导致。强范围匹配仍可能因为费用不明而只能待核；高可信来源也可能证明明确不匹配。

有效理由应包含可核查对象，例如：“本稿的主要贡献是 X；该刊官方范围接受 Y；近期论文 A 在问题/证据形态上相近，但其 Z 验证本稿未具备，因此建议定位为……”。不要复用通用的“国际知名、影响力高、主题相关”。

## 何时停止

当已有足够可行选择、关键硬条件和首投差异已核实，新增检索只重复同样结果时即可交付。作者只要三本就不扩成几十本。若没有满足所有硬条件的选项，输出“当前未找到全部满足的候选”、最小冲突和待核线索；放宽哪一条留给作者，不能暗自放宽后称符合。
