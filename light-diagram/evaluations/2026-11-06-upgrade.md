# light-diagram 与四个子技能 0.2.0 升级记录

日期：2026-11-06。范围：light-diagram 总入口、prompt/Illustrator/PowerPoint/Visio 四个子技能，及公共目录源中对应五项与生成引用。未安装到全局、未改插件缓存、未读用户生图密钥、未修改真实科研项目。本轮没有真实生图 API 调用或模型行为评测。

## 基线与实际问题

- prompt 原有 45 项离线测试通过；三份历史 handoff 只读核对通过。
- 旧 handoff 对根数组、brief 数组、数字 path/hash 等输入会抛异常。visual/science 未绑定实际受检文件，更新 artifacts 哈希后仍可能保留旧检查。
- Illustrator 的关键验证依赖 assert，Python 优化模式可能跳过；三后端均有容器、空路径、数值或样式预检不足。PowerPoint 验证要先加载 authoring runtime，不能独立离线运行。
- PowerPoint 对已打开的同名未保存文件缺少执行前保护；原生审计缺 scene 哈希。Visio 审计缺最终 VSDX 哈希。
- 项目级科学原件、Memory 恢复、稿图/评审修订与宿主已授权 fallback 的衔接需要补齐。

## 修改

1. **项目与科学依据**：新增按需读取的 project-integration.md；父子入口均明确先读有关 Memory，再回原论文、设计、分析及采用稿图版本。区分视觉参考与科学原件，保留读到的范围、FIG/版本、关键关系、假设与证据边界。与 Write/Chart/Review 按具体问题往返，实质决定和未决问题形成有来源的记忆增量。
2. **交接 1.1**：修订身份、可选父版、科学来源及定位；记录 passed/failed 时用 subjects 绑定受检文件，原生审计同时绑定最终文件与 scene。输出降级不能声称原始目标已完成。旧 1.0 兼容并给范围警告；历史结构化 source_scope 保留。只读工具核对声明和文件，不认证语义、UI 执行或科学正确性；简单任务不强制写 JSON。
3. **输入与失败**：handoff 格式错误稳定返回失败，CLI 输出 JSON，拒重复键、NaN 和数值溢出。Illustrator 改用显式验证；AI/Visio 检查有限数值、布尔冒充数字、bbox、路径、样式、端点与文字范围等。PowerPoint 新增独立 scene_validation.mjs，在加载绘图依赖前执行 --validate-only，保留两种历史修正模式拼写。
4. **原生文件保护与绑定**：PowerPoint 验证保护同名未保存修改，导出已有时拒覆盖，补 scene/connections 哈希；可见插入保护来源/目标与未保存工作文件。Visio 保存后记录最终文件哈希。Illustrator 增桥接失败诊断与验证进度；PDF 导出使用不同路径的真实 AI 字节副本，避免把再次打开同一文件误当独立文档。此 PDF 分支的本轮实际复验未成功，见下文。
5. **生图路线**：复用宿主 imagegen + 已授权 imagegen-fallback；技术不可用/失败按现有授权路由，安全拒绝不绕过，记录失败链，不另配密钥。可移植 image_service.py 仍只负责自己的同步 text-to-image 协议；本轮没有把文档路由更新称为真实 fallback 执行测试。
6. **目录**：父子复用同一 FIG；公共源仅更新五个 Diagram profile。同步实际只改对应五份 project-layout.md，全 19 份分发检查无差异。

入口为 tests/smoke_native.py，显式指定新的输出目录。材料是两个节点 A/B 和一条语义边，非研究结果；无生图、无网络、无付费调用。原始结果见 [native smoke](2026-11-06-upgrade-native/smoke-result.json)。

| 后端 | 本轮实际结果 | 范围与限制 |
|---|---|---|
| PowerPoint | **通过小型原生实测** | Artifact Tool 制作、连接补全、真实 PowerPoint 保存重开；3 个原生对象，2 个连接端点，两节点移动/还原误差均为 0。实际临时未保存文件被拒绝，且修改状态保留。使用 --hidden，未测试可见逐对象插入或完整投稿 finalizer。 |
| Visio | **通过小型原生实测** | 独立实例创建、保存重开、3 图形、两端粘附、箭头/文字及代表节点移动；最终 hash 与 scene 绑定。未测所有节点、复杂路由或全局避障。 |
| Illustrator | **建图成功，原生验证未通过** | 新建 AI 成功，验证已产生 PNG/SVG/PDF，但末尾 COM 报错 -2147417851，没有成功 audit。不能因导出存在而算通过。 |

已实际查看三个导出 PNG：A/B 标签可读，单边方向与小样一致。PowerPoint/Illustrator 保留预定画布边距；Visio PNG 更贴近绘图区，未将其当作逐像素布局等价。无真实科学内容可用于科学正确性评估。

Illustrator 的代码检查同时发现 PDF 临时文档使用同一路径 open 的别名风险，已改为独立字节副本。使用新 stem 做一次修订后复验，COM 立即再次失败且没有新进度/审计；**不能证明该修订分支已成功执行，也不能把别名风险确定为此次故障根因**。见 [follow-up](2026-11-06-upgrade-native/illustrator-followup.json)。未关闭或重启用户应用，未循环重画。现有 AI 与失败前导出保留供诊断；恢复桌面桥接后需以新 stem 重新验证。
