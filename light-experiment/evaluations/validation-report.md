## 自动化覆盖的关键反例

- 草稿可导入但不能升级为正式运行；pilot 外的后续未就绪阶段不妨碍合法 pilot。
- 设计身份不匹配、依赖成环、资源/门槛未解、范围越界会拒绝准备。
- 覆盖已有工作区、复用已启动 run ID、路径穿越、污染的旧输出目录被拒绝。
- 准备不启动进程；输入、准备配置或指定数值环境变化会在启动前阻断。
- 命令参数逐项传递，shell 元字符保持字面量；不记录任意凭证环境变量。
- 退出 0 但无原始输出不算完整成功；退出 7 保留真实状态、stderr 和部分文件。
- 真超时终止受监督的父子进程，保留证据；生效时限受批次剩余预算约束。
- 失败也消耗尝试次数；改写预算相关结果文件不能获得额外运行。
- 运行中输入变化、封存产物被改或新增未登记文件会被发现。
- 依赖运行需显式 QC 通过，其证据漂移会阻止后续运行。
- 进程失败/产物缺失不能通过 QC；指标要求有限值或 null 和实际来源位置。
- 评估更正追加保留历史；事件发生时间未知保持 null，写入时间单独记录。
- 中断尝试阻断重复工作；已记录 PID 存活时拒绝恢复，真正恢复不伪造结束时间。
