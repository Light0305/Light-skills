# light-review 0.2.0 本轮升级与验证

2026-11-06 启动，跨日于 2026-11-07 收尾。只维护本工作区技能源码、Review 对应的公共目录条目及本轮隔离验证材料。未修改全局安装、插件缓存、真实研究项目或既有评测文件。历史来源审计保留原日期，本轮未重新全面检索来源。

## 基线与已复现缺口

原有 24 项工具测试通过、无跳过；保留原有先理解再批评、跨学科证据标准、严重度与证据状态分开、科学/投稿就绪分开及 addressed 不等于 verified 的方法。

在隔离合成材料上复现：

1. 非完整评审可声明材料 not_read，却引用它作为 passed 检查及主张证据。
2. scope=recheck 可以不关联前轮，删掉旧问题后仍通过单记录就绪一致性检查。

原始复现见 [baseline-reproduction.json](2026-11-06/baseline-reproduction.json)。这两项是记录工具的可追踪性缺口，不是对真实科研论文的发现，也不表示脚本应负责科学判断。

## 修改

- 入口升为 0.2.0。恢复相关 Memory 后回读实际稿图/科学原件，明确 Workflow、哈希及上游工具通过的能力边界。
- 检查、主张、问题、改判及关闭证据只可引用 inspected/partial 的材料；partial 不冒充完整阅读。已作判断的主张位置也须在已读范围内，无法阅读时仍可诚实报告不确定性。
- 可选 Review 记录 1.1 绑定直接前轮 packet ID 与报告实际字节 SHA-256，CLI 增加成对前轮参数。packet 本身仍为 1.0，Write 的可选稿件 packet 仍为其原生 1.0，二者不混用。
- 跨轮保留全部旧 LR ID；新 ID 超过前轮最大编号；改变问题定义、严重度、必需性或关闭条件需要改判理由和本轮证据。不能靠删问题或无依据降级清空清单。
- 关闭记录绑定当前 packet 并解释检验结果。继承未变的已关闭问题需核对角色、字节、锚点和问题定位，并声明适用性未变；变更或重新打开问题仍可正常进行。报告只认证直接前轮机械比较范围，不递归认证历史。
- 旧记录 1.0 仍可核对；旧版未绑定 recheck 返回明确 warning，不伪造历史核验。重复 JSON 键拒绝覆盖，中文路径错误可按 UTF-8 输出。
- 路由补齐 Write、Chart、Diagram、Analysis、Design/Experiment、Journal，保留旧 figure-workflow 标签兼容。接入当前 Write auditor、Chart source_binding、Memory/Workflow 的真实能力和限制，去除历史本机地址依赖。

工具不能认证真实阅读、自然语言锚点、科学充分性、图面质量或独立评审；变更说明存在也不证明其理由正确。没有提供的历史、未列依赖及科学适用性仍需实际检查。局部任务不强制整套记录。

## 三轮实际文件演练

可重跑 [run_revision_exercise.py](2026-11-06/run_revision_exercise.py)，需提供一个不存在的输出目录：

```text
python -X utf8 -B light-review/evaluations/2026-11-06/run_revision_exercise.py --out <新的隔离输出目录>
```

本轮产物见 [exercise/result.json](2026-11-06/exercise/result.json)。执行者生成并实际读取合成 CSV、正文、计算代码与结果；运行本地 Python 描述计算、Write 原生 auditor 和 Review freeze/validate，12 次命令均返回预期结果，其中两次是预期拒绝。没有模型或外部服务调用。

三站点的 A/B 值为 X 0.72/0.70、Y 0.68/0.65、Z 0.53/0.55。实际计算宏平均约 0.6433/0.6333，A 平均较高但 Z 较低，只支持这个合成样本的描述。

| 轮次 | 实际稿件与复核 | LR-001 | 本轮科学状态 |
| --- | --- | --- | --- |
| 1 | 摘要和结论都声称逐站点更好，与 Z 数据冲突 | open | hold |
| 2 | 摘要已收缩，结论仍保留逐站点强主张 | addressed | hold |
| 3 | 摘要、结果、结论共同保留 Z 例外，实际重读相应位置 | verified | not_assessable |

最后仍为局部审查，不宣称完整科学/投稿就绪。三轮数据文件未变，Write auditor 均通过字节/锚点核对；前两轮仍报告未决主张 warning，说明工具通过不能证明主张成立。Review 第 2、3 轮均实际核对直接前轮；删除 LR-001 或复制前轮关闭标记均退出 2，详见 [删除问题拒绝](2026-11-06/exercise/logs/reject-dropped-issue.json) 和 [旧关闭标记拒绝](2026-11-06/exercise/logs/reject-old-closure-stamp.json)。

这里的判断由同一执行者按已知合成材料作出；不是独立模型发现问题的能力评测。未审图、未做完整论文/引文/政策核查，也未在该演练中执行 Memory/Workflow 运行时接入。
