**F01：有限任务观察支持小幅正平均，未达到实质门槛。** 固定四任务等权训练期望差的探索性近似 95% 区间为 [0.00109046, 0.00390954] accuracy，即 [0.1090, 0.3910] 个百分点。计算为 `d = mean_t(mean_A,t − mean_B,t)`；`V = (1/16) sum_t(s²_A,t/3 + s²_B,t/3)`，SE=0.000645497，Welch–Satterthwaite df=11.7647。区间只覆盖这四个固定任务/划分的训练随机性，假定各训练运行及单元独立、分数分布适合正态均值近似；每单元 n=3 无法检验这些分布假设。在这些条件下，数据与“固定四任务具有 +1 个百分点平均收益”不相容；不能外推为整个任务领域排除了该收益。

## 具体后续交接

主路由 `light-design`，由 F01–F03 触发。先修复最早的识别缺口，再决定是否值得执行；现有证据尚未以足够精度排除核心领域预测，因此没有依据直接宣布 idea 已被证伪。

下一阶段的最小交付是一份**新版本设计 brief/方案**：

1. 定义目标应用领域、任务纳入排除、任务选择框、任务异质性与等权政策；说明如何获得具有外推依据的新独立任务。原四任务保留为开发/历史材料，不能复制到新目录当独立确认集。
2. 冻结主要 A−B 宏平均、继承的 +0.01 实质门槛、主要比较、缺失/失败分母和评价验收。明确新任务上的方法版本、调参/测试接触与公平资源条件；保存测试分母与预测。不能事后以 T01/T02 定义成功子域。
3. 以任务为增量信息单位，规划足够的独立任务与必要训练重复；对多种合理任务方差和效应情景做前瞻精度/功效规划。不得把观察到的 0.0025 直接当真值做 observed power，也不得用增加原任务 seed 替代新任务。样本数需要目标域、成本和预算后才能定，本报告不编造数量或费用。
4. 在新数据前冻结信息上限、停止条件、独立验证范围及结果到决定的映射。原设计/idea 身份未提供；日后取得后保持版本与选择链，记录本次已见结果。`handoff.json` 是修订请求，不是原生 design ingest API。

建议在设计中冻结如下决定框架（它是面向未来的建议，不是追认原计划）：

| 新设计得到的证据 | 决定 |
|---|---|
| 独立且外推有效，新任务主要区间下界超过 +0.01 | 支持限定领域的实质收益；再交写作，机制另需证据。 |
| 充分有效且精确的主要区间上界低于 +0.01 | 在该范围排除原声称的实质收益，转 light-idea 重审贡献或停止；小正收益不升级为达到原门槛。 |
| 区间仍同时容许实质收益和损害/未达到预定精度 | 仅在预定预算和有效增加任务信息的方案允许时继续，否则 hold；不追跑到显著。 |
| 平均掩盖可重复的内容异质性 | light-idea 重定义有根据的范围，并用新的独立材料确认；不能事后挑选赢家。 |
| 发现评价或执行无效 | 暂停受影响比较；已有设计可修复时回 light-experiment，否则先改设计。 |

优先级依次为目标域/选择识别、评价有效性、前瞻精度与预算。剩余预算未知，不能声称实验投资有正收益；继续价值目前仅在于低投入地判断下一轮是否可识别、可支付。设计阶段在给出以上方案或确认不可行后停止；执行须有明确预算及授权。重启条件是目标框、评价条件、任务与训练重复的精度依据、成本上限和执行授权均落实。旧任务再加 seed 不能作为唯一重启依据。
