Leader 的工作方式 Memory/

先恢复，再核对，
再行动。

新的一轮对话不必从头讲起。Leader 先读项目记忆，再回到原件核对实际状态，然后把下一步交给合适的技能。

  1. 01

    先恢复

    读取 Memory 与交接。为什么改方向、哪个方案失败过、哪些约束仍有效，每条都带着来源。

  2. 02

    再核对

    回到论文、代码、运行结果和采用的稿图确认实际状态；来源变了或相互冲突，就提醒重新核实。

  3. 03

    再行动

    把下一步交给合适的技能。研究或修稿的实际增量写回 Memory，下一轮从这里接上。

安装 light-*/

发一句话给 Agent，就能装好

先选择全局安装或当前项目安装，再按技能表装所需技能。项目级安装应先进入目标项目目录。

从 https://github.com/Light0305/Light-Science 安装科研 skills。
先让我选择全局安装或当前项目安装，再按 README 的技能表安装所需技能。

粘贴到 Claude Code、Codex 等 Agent 的对话里。它会先问你装到全局还是当前项目，再按技能表安装。

PS> npx.cmd skills@latest add Light0305/Light-Science
PS> npx.cmd skills@latest add https://github.com/Light0305/Light-Science/tree/master/light-chart/skills/light-chart

在 PowerShell 中运行。第一条装顶层技能，第二条补装嵌套目录里的 Chart。第二条会再问一次 Agent 和安装范围，请和第一次选得一样，否则 Chart 会装到别处。只装一项时加 --skill light-write。

$ npx skills@latest add Light0305/Light-Science
$ npx skills@latest add https://github.com/Light0305/Light-Science/tree/master/light-chart/skills/light-chart

在终端中运行。第一条装顶层技能，第二条补装嵌套目录里的 Chart。第二条会再问一次 Agent 和安装范围，请和第一次选得一样，否则 Chart 会装到别处。只装一项时加 --skill light-write。
