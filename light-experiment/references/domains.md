# 计算实验的领域适配

只读对应部分。这些是实施中容易改变结论的检查，不是重新设计全部研究。

## ML / 训练 / 消融 / LLM 评价

- 保存 dataset/revision、split 生成代码与实际成员或其清单指纹、预处理拟合范围、去重与样本过滤。分组、时序和空间依赖沿设计处理。预训练数据未知时保留潜在污染限制。
- 记录模型/预训练权重 revision、tokenizer、有效 batch、累积/并行、步数或 tokens、优化器/调度器、精度、种子和数据顺序、早停和 checkpoint 选择规则。保存逐种子/折/任务的原始预测及目标或可重新算指标的充分记录；敏感目标保留在原有受控存储。
- 训练随机种子不是测试样本数量；fold 之间的相关性也不能忽略。基线的调参范围和选择预算要可比。消融改变参数量/计算量时说明影响，不直接判定机制。
- LLM/API 记录实际模型 ID/日期或快照、prompt、采样参数、工具/检索版本、请求与响应 ID、费用/用量和错误/重试。可控时保留原始响应；不要在日志保存密钥。模型服务更新或不可固定后端时，不承诺逐字复现。
- 确定性：记录算法开关、cuDNN/BLAS、硬件和线程；固定 seed 仍可能受异步、算子和浮点归约影响。需要统计重现时按设计记录分布与容差，不能“多试几个 seed 选最接近论文的”。

## 数值求解 / PDE / Monte Carlo / 科学仿真

- 固定模型方程/实现、参数单位、初边界条件、几何/网格、离散化、时间步、积分/求解器、收敛阈值、精度和线性代数后端。记录实际迭代/终止原因，容差命中并不等于真实误差足够小。
- 用解析解、制造解、独立参考或经说明的高精度解验证；保存参考解的版本、构建过程和误差预算。网格/步长/阶数收敛检查不把同一轨迹上的网格点当独立实验。
- 记录误差范数、残差、守恒/稳定性及物理约束；把离散误差、求解误差与模型误差分开。NaN/Inf、非收敛及不可行解保留失败类型和轨迹，不用任意插值让曲线变好看。
- Monte Carlo 固定 RNG 算法、seed/stream/substream、并行分流、样本路径和停止规则。报告 MC 误差；复用同一随机流做配对比较应记录其设计目的，不能假称独立重复。
- 输出保留解场、轨迹、样本或足以复算目标量的格式，连同坐标、单位、维度顺序与精度；只保存最终标量通常不足以重查科学计算。

## 算法 / 优化 / 复杂度实验

- 固定实例来源/生成器与 seed、规模和困难度、约束/可行性、预处理、停止容差、时间/评价次数预算和硬件。区分精确答案、可行解、最优性证据、gap 和启发式结果。
- 小实例与穷举/独立实现对照；记录退化和不可行情形。超时、内存溢出、不收敛分别报告；不能把未完成实例当作零目标值或只比较共同成功的易例而隐去其余。
- 保存逐实例的目标值、质量证据、运行时间、搜索轨迹和终止原因。比较 runtime 时确认双方解质量/精度目标相同；复杂度外推保留输入分布与拟合限制。

## 系统 / 吞吐 / 延迟 / 性能基准

- 固定 CPU/GPU/内存、拓扑、驱动、编译器 flags、库、线程/affinity、功耗/频率约束（若可控）、容器和并发负载。无法隔离的竞争明确记录。
- 定义计时边界：含不含 I/O、数据搬运、初始化、编译、缓存命中、排队和端到端开销。编译器/JIT 的冷启动与稳态分开；比较相同精度、批量、形状、并发和质量。
- GPU/JAX 异步执行需同步或使用框架支持的计时方法；测函数返回时间可能只测到提交。预热不混入稳态分布，原始每次读数留存。循环里多次计时不自动形成多个独立机器环境。
- 延迟保存分布、重复/聚合方法、请求混合、并发与吞吐；只报平均值可能隐藏尾部。性能提升也须校验数值正确性/任务质量，不把省略实际工作当加速。

## 外部集群与非 Python 项目

沿用 Slurm/PBS/批处理、MPI、Make/CMake、R、Julia、MATLAB、C/C++ 或已有工作流入口。保存提交脚本、展开配置、job/array/task ID、节点/资源请求、调度状态及原始标准输出错误；通过真实完成状态、退出码和产物验收证明结束。排队耗时与计算耗时分开。

本地调用 `sbatch` 成功只代表提交，不能拿 local runner 的退出 0 作为远端研究完成。把调度器证据、原始路径和哈希纳入手动记录，见 artifact-contract 的外部运行适配。先确认旧任务状态再续跑；分布式各 rank 的 seed、分片和归约设置均可能影响复现。
