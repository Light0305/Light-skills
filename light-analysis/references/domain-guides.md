# 按实验领域分析

只读对应部分；跨领域任务同时保留各自误差来源。

## ML、强化学习与 LLM/agent

- 区分模型实例、训练算法、超参数选择过程、数据集和任务集合。对每个对比标注训练/选择/评价预算及实际实现差异；文献数字不能默认和本地评价可比。
- 核对评价脚本/版本、split、去重、个体/时间泄漏、预处理拟合范围和所有测试集接触。模型选择不得偷看保留集；重复使用公开 benchmark 的开发不能当成独立新任务总体保证。
- 每个 seed/fold/数据集保留对应 ID。相同 seed 本身不能证明配对；用同一测试单位的对应预测可以支持匹配的配对分析，但固定预测的区间不覆盖训练选择过程。
- 跨任务先看每任务的效应和异质性，再用有依据的任务归一化、权重和稳健聚合；rliable 的 IQM、performance profiles 和分层 bootstrap 可借鉴，不能对任意不同量纲数值直接算 IQM。既报告汇总也保留明显受损任务。
- 检查训练/验证曲线、过拟合、checkpoint 选择、梯度/损失异常、目标是否被使用，以及评价器是否易被优化漏洞影响。曲线很多点不是很多独立样本。
- LLM 固定 prompt、模型/权重版本、采样设置、工具/检索语料、超时与 token/费用预算；记录每任务多次尝试。区分至少一次成功、单次成功和重复一致成功；任务内试验相关时不直接套独立二项模型。
- 对 model-as-judge，保留 rubric、judge 模型/版本、顺序、位置偏差和人类校准依据；评价器失误与被评系统失误分开。读取真实轨迹/失败产物以核验评分，不能只信总分。
- 分别报告系统失败率、未完成、任务失效、真实能力失败与条件性能；环境资源限制可能改变实际任务。重新评分要公平覆盖受影响方法和任务，保留原分与更正。

## 数值计算、仿真、优化与数学计算

- 区分建模误差、离散/截断误差、迭代误差、舍入/精度误差和 Monte Carlo 误差；随机重复不覆盖系统离散误差。
- 检查解析解/制造解、已知极限、守恒量、不变量、量纲与边界/初值。小残差不必然小解误差；条件数/非唯一性可能使残差具有误导性。
- 网格/步长细化要确认处于合理收敛区域、其他误差充分受控；说明参考解、误差范数、实际阶数与饱和/不收敛。没有收敛阶/结构依据不自动 Richardson 外推或填 GCI。
- 仿真报告模型假设、输入参数范围及其依据，区分参数不确定性与数值近似。只在模拟系统成立的结果不自动外推到现实；用合适校准/外部数据说明可迁移范围。
- Monte Carlo 概率/均值报告有效独立信息与模拟误差；相关链用适当 ESS/MCSE。把参数估计区间、后验不确定性和模拟近似误差分开。以合成数据检查方法是验证，不是用户真实实验结果。
- 优化报告目标定义、可行性、最优性 gap/下界、停止标准和预算；比较达到相同精度的成本以及相同成本的精度。有限迭代最优值与已证明全局最优分开。
- 理论主张逐条核对假设、证明依赖和反例条件；有限数值验证只能支持某些实例。找到合法反例可以否定普遍命题，没找到反例不能证明命题。

## 算法与系统基准

- 先定义 workload、输入规模/实例、正确性/解质量、环境/硬件、并发/线程、编译优化、冷/热缓存和预热；计时边界包含或排除的数据准备/编译需明说。
- 计时顺序、机器/日期和共同负载可能造成相关与漂移。区分同一进程重复读数、独立启动和独立实例；优先在可比 workload 上配对、按实例汇总，避免用大量连续读数夸大 N。
- speedup 写清分子分母、每实例比值与汇总权重。几何均值适用于明确的正比值和相应目标，不能平均不同比值定义或对 0/负数取 log。
- 超时/OOM 保留失败类别、总分母和上限；不只比较全部成功的小子集。time-to-solution、性能剖面或删失分析需相应目标与假设，不能把超时当恰好在时限完成。
- 展示准确性/解质量—时间—内存/成本的权衡；加速若牺牲精度，结论应限于真实 Pareto/约束比较。Benchopt 可启发统一 objective 和停止标准，不替代领域正确性验收。

## 一般定量、成像、组学与观察性研究

- 定义实验/抽样/分配单位及 batch/site/subject 等层次。细胞、图像块、孔内读数和同一人的时点不能直接当作独立受试者。
- 处理与批次完全混杂时，事后 batch correction 通常不能恢复原本缺失的识别。报告可描述的事实并回设计，不承诺靠更复杂回归消除问题。
- 明确测量范围、LOD/LOQ、饱和、归一化/批次校正、背景扣除与 QC 排除的实际规则；强处理会改变目标量，保留原尺度与合理敏感性。
- 高维检验先定义比较族、适当 FDR 和效应阈值；富集分析报告实际背景集、数据库版本与选择流程。图像定量和统计样本需要同一实验身份链。
- 观察关联、预测和因果效应分开。因果主张依赖识别假设、时间顺序、混杂/选择/中介处理与适当设计，不能由模型拟合好或控制很多变量直接推出。
- 若用户只需要统计报告审查，可衔接可用 nature-statistics；实际临床或法律等决策的额外要求依真实任务处理，不为所有基础研究套临床工作流。

## 定性与混合研究

从真实材料、编码与案例选择出发，保留分析者解释、反例和不同来源证据的关系。明确饱和/信息充分性的依据及未覆盖范围；不把编码出现次数当无偏总体频率。混合研究说明定量与定性分歧如何影响判断，不强行抹平冲突或补一个 p 值。
