When images contain both object features and background cues, performance on an unchanged split can leave unresolved how strongly a model depends on each. Learning from full images, as baseline B does, permits both sources of information to contribute. Restricting feature aggregation to foreground regions offers a way to examine whether reducing access to background cues during training changes this dependence. The central question is therefore a trade-off: whether foreground restriction improves performance when backgrounds change, and what it costs on the original split.

We investigate this question in a synthetic computer-vision benchmark using method F, which uses supplied foreground masks during training but requires none at inference. F and B share a backbone and train/test split; a cross-background test changes backgrounds while preserving object identity. F scores lower on the original split (81.2% versus 83.0%) but higher under background changes (74.5% versus 62.8%). This contrast supports foreground-restricted training as a candidate for reducing background dependence, while the single training run per method leaves the reproducibility of the trade-off unresolved.
