# 计算实验执行记录

## 本轮范围

idea/设计 ID 与版本、实验/任务范围、原始设计位置与冻结快照；实际执行者与时间。区分正式实验、pilot、开发验证和事后整理。

## 实现与实际运行

关键方法如何对应代码；真实入口、配置/输入/环境版本及设备。列计划条件与独立单位、实际运行 ID、状态和证据位置。基线、公平预算与评价边界说明。

## 原始观测与验收

原始日志/产物/逐单位值位置与数据字典；技术状态、质量判定、科学比较分别说明。每个报告数值附具体来源和派生步骤。报告负结果、缺失和不确定性，不只列最佳运行。

采用的前置运行和 assessment 版本、当前 QC，以及后续更正影响了哪些直接/间接依赖。区分已复核和仍需复核，旧原始记录保持。

## 失败、偏离与投入

失败与修复、重试/续跑关系、配置变化、排除及原因，说明发生于查看结果前或后。所有尝试的实测时间与已测资源，无法核实的值保留未知。

## 当前决定和复跑交接

按设计判定支持/反驳/不可判定，说明可解释范围。未运行、仍在排队/运行和未通过质检的项目单列。交付真实复跑入口、所需输入/环境/访问、容差、待解决问题和下一步。

执行 verify 的实际结果与未消除警告；向分析显式提供的原始文件及身份。记录提交到 Memory/Workflow 的增量与来源，避免把完整性检查或归档状态当作科学验收。
