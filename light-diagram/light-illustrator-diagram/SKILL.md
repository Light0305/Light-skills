# light-illustrator-diagram

## 项目目录与续作

需要落盘或继续已有项目时，先读 [项目目录约定](references/project-layout.md)，按其中的本阶段位置、版本与关联规则保存；用户指定路径和旧项目优先。包内资源相对本 skill，研究产物相对真实项目，二者不要混用。只做局部讨论时无需初始化目录。

以用户指定的参考为视觉目标，交付可编辑 `.ai`、实际导出预览及来源/修正记录。先保持科学关系，再逼近布局、轮廓、颜色和纹理。照片、显微证据和数据图有各自的制作流程，不能靠矢量装饰或生图补出结果。

由总入口 [light-diagram](../SKILL.md) 调用时，先读取案例的 [共同交接记录](../references/routing-and-handoff.md)：复用已选参考、科学 brief、标签、关键关系和修正清单，核对来源哈希；不要自行重新生图或换参考。使用本工具的专用 scene 和实际原生检查，将最终文件、预览及分开的检查证据回写交接。直接指定 Illustrator 的请求可独立执行，不强制先走提示词和生图。

持续项目先查有关 Memory，再打开原论文/设计/分析及采用的稿图版本核对；记忆摘要不替代原件。直接调用时也保留科学来源定位、FIG/修订身份、已知错误与编辑边界。换版复核受影响的场景、原生文件、导出和科学关系，将采用版本与图注/术语变动交回 Write/Review，并给 Memory 有来源的决定和未决问题；简单修图不强制创建完整交接。

## 读图与路线

实际查看参考，记录文件、尺寸、哈希、图号或生成提示词。读取已有科学关系检查，辨明图元、箭头、分组、层级和局部放大。参考错误需要明确交付“按图复现”或“科学关系修正版”；保留原图和具体改动，不静默纠正。不要把未知关系补成猜测的因果链。

先发现可用 Illustrator 工具；能力足够时优先用已连接的原生工具。本包在 Windows Illustrator 2026 的实际路线是 Python COM → ExtendScript → 原生路径和文字，不要求安装参考仓库或改全局配置。版本、工具研究与故障处理见 [运行与工具](references/runtime-and-tools.md)。

选图时区分复杂性：多尺度结构、互相约束的机制、曲面轮廓和跨模块路径比大量重复圆点更能检验复现能力。比较工具时可复用同一参考，并明确本轮没有重新生图。需要新参考或局部位图时，使用可用的生图工作流；保留实际执行提示词，修订而未执行的提示词不能标成验证过。

## 可编辑重建

- 区域、组件和关系使用有意义的图层/分组及稳定 ID。贝塞尔锚点和左右控制柄保留为原生路径；孔隙可用实际复合路径开口，避免仅以背景色椭圆冒充透明孔洞。
- 先匹配轮廓、空间关系和色彩角色，再增加必要的渐变、细节。纹理近似须说明，不能用重复颗粒或对象数量充当还原质量。
- 文字保留 TextFrame，选择实际安装且支持所需字形的字体。化学式优先用普通数字加原生下标范围；特殊箭头可显式指定字形字体。脚本返回的字符串正确仍可能显示缺字，必须看实际 PNG。不要把成品文字统一描边来隐藏问题。
- Illustrator 关系线是可编辑路径和箭头，不具备 Visio/PowerPoint 的原生节点吸附。保存来源、终点及方向元数据。移动内部结构可分组；跨组关系需要重算或明确重画，不能承诺自动跟随、避障。
- 难以矢量化的局部素材可以保留位图，但需列明来源、占用区域及可编辑边界。整图平铺、自动描摹大量色块或嵌入整页 SVG 都不能代替语义重建。

可运行的纯矢量场景格式与命令见 [场景与制作](references/scene-and-authoring.md)。随包脚本接收经过人工检查的结构，不自动识图，不调用生图服务。复杂曲面、剪切蒙版、网格或照片素材若超出当前渲染器范围，使用原生工具另行制作并实际验证，不静默降级。

## 用户观看过程

桌面 Illustrator 可用时，尽早打开目标工作文档。用户要求看过程时，在可见空白画板中逐个或小批实际创建图元，重绘窗口并记录顺序。`scripts/illustrator.py render` 支持真实原生创建与可调速度；它不会插入成品后用显隐动画模拟绘制。不要同时向同一 Illustrator 实例派发绘制和检查。

只操作指定路径或本次新建文档；保留其他文档和未保存编辑。失败时保留新文档与日志，检查出错点，再用新候选名迭代。现有成品不覆盖。窗口可见不等于用户一定观看了全过程，报告实际执行方式。

## 分开验收

1. **文件与编辑性**：真实 Illustrator 保存、重开指定 AI，读取路径/复合路径、文字、图层、图片和外链。不得只检查一个 SVG 文本文件就声称 AI 可编辑。
2. **原生几何与文字**：读取实际锚点和控制柄、闭合性、关系端点与箭头；复合路径保存后可能改变起始锚点或绕向，应核对等价几何。检查文本字面内容、原生上下标范围及实际字形容纳。
3. **分组行为**：临时移动需要整体编辑的组，核对内部对象位移并恢复。丢弃探测改动，重开已保存文件后导出。明确是否包含跨组关系，避免把面板整体移动说成自动重连。
4. **视觉与科学**：查看最终 Illustrator 导出的每张 PNG，检查缺字、裁切、叠压、走线、孔洞、层级、方向和放大层位。像素指标只用于定位差异；文件或几何通过不能代替这一步。

详细检查与局部修复方法见 [复现质量检查](references/reconstruction-and-qc.md)。发现问题后修复并重做相关检查；分别说明文档检查、应用实测、目视检查和科学复核的范围。

## 交付

最终 AI、PNG、可选 SVG/PDF、参考、场景、来源记录和简短报告。SVG/PDF 的文字与编辑性单独检查，不能由 AI 结果推定。说明位图、纹理近似、源图修正、字体要求和尚未测试的行为。保持最终 AI 窗口可见，方便用户继续编辑。

已实测的复杂案例：[锂硫电池同图对照](evaluations/2026-10-30-lis-comparison/REPORT.md) 和 [交互比较](evaluations/2026-10-30-lis-comparison/compare.html)。该案例检验一条本机工作流，不代表所有领域、版本和图型均已验证。
