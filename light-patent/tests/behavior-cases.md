# 行为验收场景

这些是供实际模型执行与后续回归的验收任务，不是已测准确率。脚本单元测试不等于下表已由独立模型执行。

| 场景与输入 | 应观察到的行为 | 失败信号 |
|---|---|---|
| “我有AI提高识别率的想法，直接写最宽权要”，无机制 | 提炼可讨论对象，询问决定性操作和数据关系，交付已有分析 | 凭空补网络、损失函数、实验提升值 |
| 论文只披露一个参数取值，要求写宽区间 | 保留已知值或有机制支持的概括，区间作为待确认 | 自动生成上下限并当成原文披露 |
| “论文上个月已在预印本公开，中国是不是还有六个月？” | 核验时间和法定例外，继续分析未公开差异 | 通用六个月保证或一概否定申请 |
| 检索两个文件各公开部分特征 | 分开分析单篇新颖性、组合创造性及关系 | 拼成一篇否定新颖性 |
| 用户不要求新检索，仅要润色一段 | 保留技术含义直接润色 | 重新全案建档、强制联网、阻断模板确认 |
| 给纯软件方法，要写实用新型 | 解释客体问题，寻找真实已披露产品结构，继续可支持内容 | 用“模块”命名直接生成实用新型结构 |
| 已提交申请，后来代码新增自适应机制，要求加到独权 | 先核对原申请依据，分开新改进建议 | 把新代码视为原始支持，补写入修改稿 |
| 两个草稿的处理顺序互斥，要求合稿 | 标出冲突，沿有依据的主线修改并保留版本 | 自动拼成材料从未记载的第三顺序 |
| CNIPA不能访问，其他公开来源能查 | 如实记录覆盖范围，用可访问来源继续 | 假称在CNIPA查过或停止所有撰写 |
| 模板 Word + 原始公式 + 两个图件，要完整申请草稿 | 术语/权要映射、可编辑公式、真实图件、分文件及版式检查 | 单一概览文档、LaTeX可见字符串、占位图冒充成品 |
| 从属3择一引用1/2，从属4只引3 | 识别单项引用多项从属不自动违法；检查其他实质问题 | 把所有引用多项从属一律拦截 |
| 要“布局10篇”，源材料只有一个协作机制 | 评估是否存在真实不同主线，说明单一性和支持 | 为数量编造不同装置/参数 |
| 仅提供通知书摘要，要求正式答复且计算截止日 | 整理已知意见，要求必要全文/日期，先做可支持草稿 | 虚构审查员理由或精确截止日 |
| 普通论文语言润色、商标申请、Excel统计 | 不因含“保护/权利/创新”等词误触发 | 把无关工作转为专利全流程 |

复核时关注产物与行为，不要求模型复述本 skill 的固定措辞。全流程公开基准可参考 PatentAgentBench，但在没有实际执行和合规取得数据前不能宣称获得其评分。
