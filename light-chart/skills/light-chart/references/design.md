# 设计：把证据变成可阅读的图

综合 nature-figure 的设计/证据架构、FigMirror 的紧凑度与线条校准、figures4papers 的实际排版经验。参数是起点，不是官方期刊规定；先看 [视觉库](visual-library.md)，再决定本图需要哪些规则。

## 图面与图注的边界

论文图默认不加介绍性总标题、解释副标题和长脚注。它们在稿件 figure caption 中，而不是画布中的顶部/底部说明栏。误差定义、样本单位、来源和方法仍需完整交代，单独交图注；图面只保留读图必需的坐标、单位、身份、尺度与短条件标签。实际需要的指标名/组名不是装饰，不能一起删掉。

精简后重排数据区和面板间距，不保留给旧标题与脚注预留的空带。减少重复编码（同一分组已由分块标题清楚表示，就不再自动加一套同义注释条和图例）。不以缩小字号、删除组别或省略区间来获得“干净”。

## 从阅读问题分配面积

先说清“读者要比较谁、判断什么”。把答案最快的编码放在主位置，必要的对照和限制围绕它组织。六张随机图拼在一起仍然是六张随机图。

- 方法验证：整体比较 → 分条件是否保持 → 组件贡献或失败边界。每个指标不必单独获得一个主图面板。
- 实验验证：主要响应 → 个体差异或正交测量 → 扰动/边界。避免用示意图填空，不虚构显微照片。
- 样本矩阵：类别/样本分组 → 共享尺度 → 必要注释条/例外。先保留身份和量纲，再决定聚类。

主证据可跨列；辅助图可小一些。等宽网格适合对称的比较任务。不等面积需要实际阅读理由。

## 最终尺寸的视觉系统

先指定输出宽高，再以最终 pt/mm 设计。180 mm 宽是本包示例的选择，不代表所有期刊的统一要求。

| 元素 | 紧凑论文组合图的试画起点 | 调整依据 |
| --- | --- | --- |
| 正文、坐标标签 | 7–9 pt | 最终尺寸直接可读；中文、数学符号另检 |
| 刻度、次要说明 | 6.5–8 pt | 数字精度与可用宽度，不能无限缩字 |
| 面板字母 | 8–10 pt，粗体 | 比普通文字略醒目；每行共享锚线 |
| 面板标题 | 7.5–9 pt，中等/粗体 | 表达内容，不堆巨大空泛总标题 |
| 轴线 | 0.5–0.8 pt | 能找到坐标，不能比数据更抢眼 |
| 数据线 | 0.9–1.4 pt | 系列数、误差带与缩印清晰度 |
| 点符号 | 2.5–4 pt | 数据密度；小样本点不能藏在粗箱体后 |
| 误差线 | 0.6–0.9 pt | 与点区分；端帽约 1.5–2 pt |
| 辅助线 | 0.35–0.6 pt | 可见且退后，不用极淡颜色假装简洁 |

字体家族保持一致；Arial/Helvetica/DejaVu Sans 是候选，中文需实际安装且能渲染的常规字重字体。大画布中的 24–54 pt 不能直接当最终字号。PDF 检查包括上下标的真实字形；必要时用支持的 Unicode R²。

## 配色决定先看哪里

为变量身份、顺序或方向配色，不能只因有十种方法就拿十种彩虹色。

- 单个重点对照：中性灰蓝作背景方法，一个适度饱和强调色作关键方法；直接行标签承载身份。
- 同等重要条件：2–4 个可区分色族，加符号/线型。不能无依据地把某个条件淡到看不清。
- 同模型子型：同族色或同色加线型，跨面板映射不变。
- 有自然零点的变化：以零为中心的发散色；正负不等于好坏，方向不同的任务要说明。
- 计数、比例、强度：顺序色；比较面板共享色标。不能各列按自己的最大值归一化后暗示可比。
- 缺失单独显示；NA 不等于零。

例如灰蓝 `#8B99A6`、重点蓝 `#226D8D`、辅助青 `#288C83`、暖色 `#CA7259`，是本包示例的一组映射，不是固定“顶刊配色”。

需要换一套视觉起点时，`color_tools.palette_project("ocean", identities=["Control","Treatment"])` 可生成完整任务配置；另有 `mineral`、`orchid`，定义在 `assets/palette-families.json`。一次确定组名映射并保存，再跨图读取，不能逐面板重排颜色。类别用色与顺序/发散色带分别定义；这些色族没有期刊或色觉合格认证。先在真实整图上比较，密集线/小点要看实际对比，必要时增符号或改色。`contrast_text(cmap(norm(value)))` 依据实际填色及透明度选注释文字，不能按数值阈值猜黑白。

实际执行使用 `assets/project-style.json` 的任务副本。`groups` 是 `{"Control":{"color":"#8B99A6"},"Treatment":{"color":"#226D8D"}}` 这样的身份映射；声明后未知组报错，不按绘图顺序循环套色。`roles` 管理重点/基线/缺失色，`palettes` 管理类别、顺序和发散标度，`metrics` 记录 `min/max/none` 方向与单位。方向记录不替代当前任务的统计判断。

Python 在 `with figure_style(project="project-style.json",lang="zh"):` 内构图、导出，或使用 `project_context`；`role()`、`colors_for()`、`colormap()` 随上下文读取配置。R 加载 `publication.R` 后 `use_project_style("project-style.json")`，使用 `lc_color()` / `lc_colors()`。同一份 JSON 随整套图保存；R 与 Python 都采用 sRGB 通道插值，零中点保持原色。需要不同量纲色标时按面板明确分开。

默认 Latin 为 Arial、中文为 SimSun；可在任务副本中替换已安装字体。Python 的 Latin、科学符号回退、中文字体按字形依次选择，普通英文和数字不会被中文字体接管。R 的 ggplot/patchwork 混排在导出时通过 gridtext 明确拆分字体；原生 grid 可用 `mixed_text_grob()`。复杂 grid 自定义回调、数学表达式和特殊字体仍需实际检查 PDF；系统字体存在不保证 Cairo 使用同一字体。默认最小字号 6.5 pt，由最终 PDF 检查；这是本包阅读阈值，不是期刊统一标准。

## 以结构减少图例成本

多方法比较常适合“行名 + 多列点/区间”，无需“彩柱 + 巨大图例”。方法名只读一次，指标按列对齐。点估计可以放大科学相关范围；柱长表达数值时保留零基线，或换用合适编码。

2–4 条曲线适合一条紧凑共享图例；端点稳定且间距足够时可直接标注。不得移动数据终点给文字让路；移动标签并加短引导线。图外短条图例通常比空出一整列更经济。

注释条和 colorbar 留真实空间。先测渲染文字宽度，再分配槽位；自动布局不会判断科学主次。保持既定尺寸，不能靠 tight 裁边悄悄改变比例。

`composition.compose((180,110), [["main","main","control"],["main","main","boundary"]], panels=...)` 可建立跨行/跨列槽位。绘图后调用 `fit()`，根据最终 renderer 的文字边界留位，`labels()` 将字母锚定到槽位。panels 中可记录 role/question，设置 min_plot_mm 和 plot_aspect（物理数据区宽高比）；空间不足抛 LayoutError，不改变字号、数据或坐标范围。

并列指标/矩阵用 `balance_columns=True`，先给长行名和坐标分配宽度，再按 width_ratios 分配数据区；此模式要求面板不跨列。边缘图可用 share_x_with/share_y_with 指向主轴，维持数据边界对齐。命名曲线可用 `label_line_ends(ax)` 在真实末端外排标签和引导线，fit 时按物理间距更新；无法容纳时拆分或另留图例。

## 密度、留白与精度

- 空白留在证据组之间，压缩重复图例、单位和无用边缘。紧凑不等于把文字挤到数据上。
- 刻度先试 3–5 个主要值。时间/浓度不等间隔就保留坐标；含零剂量不能直接用普通 log 轴。
- 少量汇总热图可注释；数十个样本的矩阵依赖色标、组条，数值另交 source data。
- 单元文字按填色亮度选择，不能按数值正负猜颜色。不同色图分别检查。
- 分布图展示原始点；箱线的四分位、须和样本单位需解释。小 n 不靠平滑小提琴制造分布形状。
- 装饰性网格、面板框、大阴影、无意义渐变通常不帮助判断。

科学正确性优先：美化不能改变点位、误差、n、排序依据、分母或排除规则。参考图有截断柱轴、误导颜色或拥挤标注时，继承有效结构并修正缺陷。

审查与修订见 [editorial-review.md](editorial-review.md)；毫米布局和数据原语见 `scripts/editorial.py`。用户已有视觉系统或明确要求可覆盖试画参数。SVG 保留文本，PDF 嵌入合适字体；密集数据层可栅格化，轴和文字仍可编辑。

## 深层资料

## 实际配色检查

组配置可同时保存 Python marker/linestyle 与 R shape/linetype；encodings_for()/lc_encodings() 返回同一身份映射，组顺序变化不会换色。层级语义可用颜色表示来源、线型表示处理；不必强迫每个组合都换一种颜色。

`color_tools.audit_palette(encodings, background="white", alpha=1)` 检查实际使用的几种颜色及合成透明度，不审查整套未使用色库。输出普通、灰度和三种近似色觉模拟的 ΔE76，以及对背景的相对亮度对比。默认阈值是可调的绘图启发式，不是期刊规范或可访问性合格证明；细线、密集点和重合系列仍需实际查看。palette_preview() 生成外置色板，vision_preview(png,out,mode="deutan") 生成另存的诊断图，不能覆盖论文原图。

`continuous_scale(values, mode="sequential", limits=..., cmap=...)` 返回 norm/cmap/检查结果。发散模式必须显式 center；拒绝裁掉实际有限值，检查顺序或发散两翼的亮度单调性，不自动以均值/中位数发明科学零点。纯原色 RGB 图像保持 native RGB，不套定量色标。

导出时 audit_rendered_mapping() 比较 Python 命名 artist 或 R 实际离散颜色尺度与项目配置；配置正确而图中用错组色仍会失败。未命名标记、独立连续变量不猜作组身份，仍需核对。色觉矩阵依据 Machado et al. (2009), doi:10.1109/TVCG.2009.113；模拟是近似观察工具。
