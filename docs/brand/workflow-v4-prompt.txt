为开源科研工具包 Light-Science 设计一张可以直接放进 GitHub README 的完整科研工作网络插画。用户明确要求：直接生图、米白色背景、Q版一点、把逻辑讲清楚。横向画幅，约 3:2，清晰高分辨率，四周留安全边距。

美术方向：
温暖米白色纸面背景（近 #FFF8ED），精致的 Q 版二维手绘科研地图。人物是小巧可爱的科研助手，圆润比例，细腻但克制的彩色线稿和平涂。使用深青绿、柔和蓝、蜂蜜黄和少量暖橘作为强调色，文字用深墨色。整体亲切、有趣、有设计感，像一本优质科普绘本中的信息插图。Q版场景用于解释节点，不能盖过信息结构。图形轮廓干净，尽量少纹理，准确中文文字要有排版质量，缩小后依然清晰。不要发光、玻璃、渐变科技效果、写实人物、3D黏土质感、机械地排列一堆UI卡片，也不要花哨宣传口号。不要复用普通流程图模板。以真实的信息设计组织画面，箭头要明显、方向正确、线条不穿过文字或角色。

标题只写：“Light-Science 科研工作网络”。

必须清楚展示三个层次：
一、上方是两个相互配合的核心角色。
“light-leader”下面写“项目总控”：Q版研究负责人拿着计划本，负责理解目标、核对真实材料、选择技能、验收与继续推进。
“light-memory”下面写“项目记忆”：可爱的档案管理员或抱着档案夹的小助手，保存有来源的决定、约束、历史与失败经验。
两个核心之间是明确的双向连接，短文字“读取记忆 / 回写增量”。Leader 向下协调两组工作，文字“按当前问题选择入口”。Memory 不独立执行实验，不画成自动启动所有技能。

二、主体以两组有明显分区感但不靠巨大卡片面板的可爱工作场景，讲清循环：
第一组标题“研究循环”。五个节点按主要顺序连接：
“文献”→“想法”→“设计”→“实验”→“分析”。
每个节点只用清晰的中文主标签，搭配一个小型Q版科研场景：读论文、记录灵感、规划方案、计算机与实验装置、分析数据。研究不限于湿实验，至少有电脑/代码的意象。
有明确回路从“分析”返回“想法 / 设计 / 实验”，用一条清楚的回退路线及短说明“补文献 · 改想法 · 修设计 · 补实验”。“文献”与“想法”可以往返。不要把这个循环画成一次性的固定流水线。

第二组标题“论文制作与修订”。主要关系：
“选刊”→“写作”，写作与绘图和评审反复往返。
绘图应有两个并列的独立中文标签：“方法与机制图”和“数据图”，一个小白板画网络示意，一个画统计图；两种绘图都与写作、评审协作。评审节点标签“评审”，用拿着检查单的Q版研究员表示。
一条清楚的箭头连接研究与论文组，文字“证据支持后进入论文制作”。
从评审/论文组回到研究组有一条明确反馈箭头，标“需要补证据时返回研究”。
写作、图与评审之间的短说明为“反复修订”。
请由专业信息设计的方式自主选用紧凑、舒展的两组循环或两条路线的构图，把箭头安排清楚，不要为了保持对称而牺牲关系的正确性。

三、底部是一条体量较小的“按需接入”区域，用三个可爱的小场景而不是大卡片：
“采集”：资料与数据。
“专利”：技术成果与发明。
“软件著作权”：软件及文档。
它们是按项目需要接入的分支，不是所有项目必须走完的最后三步。
最底部仅一行小字：“一个项目围绕一篇论文或一项软著，也可关联同源成果。”

文字要求：上述中文和 light-leader、light-memory、Light-Science 必须正确，不要添加新技能名称、乱码、段落说明、英文小字和假的指标。使用简洁的印刷中文字体，人物可以Q版，文字不能难读。总体留白充足，简化装饰，在可爱和专业之间保持平衡。
