# 三维任务先分清表示

高度场 z=f(x,y)、任意网格、体素标量场、离散轨迹和装饰层叠图需要不同核对。选择实际类型对应的子指南，不要把二维数据随意拉伸成三维。

strict-reproduction 用于用户明确要求的参考构造复现；candidate-comparison 比较真实已渲染 control 与候选；control-replacement 要说明为何采用候选并检查保持项。新数据适配仍以实际数据和问题优先。

严格流程需要最终 PDF、明确的参考角色、三维子类和 geometry_evidence。再读 evidence、camera、assessment、selection、iteration。缺少资源时完成可验证部分并列缺口，不能用像素分数代替几何证据。
