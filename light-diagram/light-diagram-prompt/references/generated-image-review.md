# 从实际生图到提示词修订

适用于用户提供生成图，或明确要求执行生图测试时。核心 skill 交付提示词；调用生图模型由当前宿主按用户授权执行。本文件的规则来自实际观察，可按任务取舍。

## 对照对象与连接检查

先保留简短的“科学事实与表达范围”清单，标明依据为正文、图注或摘要。摘要只能支持其明述的概念，不能据此补出原子配位、精细装置或模型内部结构。记录有意省略的内容与是否改变图的解释范围。

复杂图用内部节点编号区分重复模块，例如 encoder_norm_1 与 encoder_norm_2。关键边分别记录源对象、终点、含义、数量。图上不必显示编号。逐条沿生成图中的实际线走一遍，不能仅凭两个模块都出现就判定连接正确。

标注线另作检查：端点必须落在它命名的对象上。贴邻的 RNA 与 DNA、晶界与添加剂、物理连线与控制线尤其容易误指。必要时给标注预留一个没有遮挡的短对象段。禁止装饰性悬空线。

对链与接口检查连续性：两条配对 RNA 仍是两条独立链，一条嵌合 RNA 才连续；颜色改变不等于共价连接；交叉不等于接通。重复括号只覆盖真正重复的部分。

多级 encoder–decoder 图还需区分“状态标注”和“装饰性特征平面”：状态名绑定到具体连线或模块输出，避免每个邻近平面再复制一个名字。相邻层的独立跳连不可被一条连续竖直总线混接。残差或门控旁路应命名其准确来源，例如“Conv 后、与 X 相加后的输出”，并检查起点有无反向箭头头部；只写“加残差”不足以限定这些细节。

## 材料与分子符号

“分子符号”“粒子图标”等宽泛词可能生成看似原子结构的球簇。没有结构依据时，应直接指定单个平面圆片或简单标签块，并说明它是概念符号。不把球数、标记数量、大小或箭头宽度当作定量结果。对照图沿用可比的视角、几何和编码；差异表示定性趋势，不能宣称图像一比一几何保持。

## 修订与回退

若主体结构正确，可将已检查的图作为编辑目标，完整说明保留项与局部更改，并保留标签清单。不要只写“修正箭头”或依赖另一份旧提示词。实际执行前先查看目标图。

每次修订后重新检查全部关键边、节点数量、标注与链连续性。一次改好 Q 输入，可能把 K,V 改接到中间层；这属于回退。记录修订是否只是改善一项，还是满足了整个预设范围。

复测次数按任务成本和进展决定；无需无限生图。结构仍不稳定时，明确剩余错误，推荐拆成概览与局部图或交给后续可编辑重建。改变范围必须写明，不能用简图通过替代原来的详细图失败。
