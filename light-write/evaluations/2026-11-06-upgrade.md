## 基线与发现

- 原有 4 项离线 harness 测试通过。
- 原结构校验通过：7 个领域模块、11 个开发案例、90 个文档路径/锚点、3 份 JSON 契约；未提供额外 run 记录。
- Draft / Polish / Check、领域/证据形态—体裁—章节—精确 venue 路由、论证推进、数值/引文/量词保护已存在，继续保留；七份领域模块均为 draft，无精确 venue 模块。
- 持续项目缺少明确的来源采用版本、更正影响检查、Journal 1.1 决定/就绪区分、Figure/Review 返修关系；旧文件授权措辞可能导致重复请示。
- 评测输出选择只看 completed 状态，未核对实际非空正文及与记录的一致性；写 record 前中断的目录可能在重试中被覆盖。结构校验对非对象输入、JSONL 重复键和数值溢出也有失败路径缺口。

## 修改

1. **项目衔接**：新增按需读取的 `references/project-integration.md`；用 Memory/Workflow 恢复上下文后回到专业原件，核对原生 Analysis 并保留警告。一个项目的一篇核心论文保留一个工作区，草稿、转投和返修在内部留版。
2. **选刊与写作**：接实际 Journal brief/packet，分开目标决定与证据就绪，保留类型、出版路线、投稿阶段、来源日期与未知；通用写作不依赖确定目标。补实际报告规范和声明的适用性规则。
3. **修订反馈**：来源更正后重读、定位受影响主张及摘要/正文/图注/补充/回复信，再采用新版。Figure 源稿不复制成新的事实源；Review 修复关联受审版本、问题和修订位置，等待实际复核。
4. **可选核对**：新增 `scripts/audit_manuscript.py`、`references/manuscript-packet.md` 和空白模板，记录实际稿件、来源、主张锚点、保护文字和前版关系。只读核对声明范围，不强制局部任务填表或落盘；不自动刷新哈希、不认证语义或投稿就绪。
5. **交付与计数**：修正已授权文件更新仍可能索要许可的规则；Word redline 要求真实修订，文件用可用文档/构建流程实际生成核验。新增 `scripts/text_metrics.py`，区分 Han 与空白分词、检查上下限，明确范围/Unicode/期刊口径限制。
6. **评测与校验修复**：实际正文非空且匹配记录才能进入评审；后一次完成稿损坏不退回旧稿冒充，显式重试保留原失败和未完成目录。JSON/JSONL 一致拒重复键，非对象输入给契约错误，非有限指标不通过。

旧 EQUATOR selecting-the-appropriate-reporting-guideline 路由实际返回 404；采用实际可读的现行 library，不将失败访问记为已核查全文。没有开展具体期刊推荐或真实课题查新。
