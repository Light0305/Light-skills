# Paper-note methods and reading list

The Phase 2 note template is a synthesis of five traditions. The goal is not a
summary; it is a durable, evidence-anchored artifact that can later support idea
generation.

## 1. What we borrowed

| Source | What we borrowed |
|---|---|
| [nature-skills `nature-paper-card`](https://github.com/Yuan1z0825/nature-skills/tree/main/skills/nature-paper-card) | Structured card contract; evidence inventory; claim–evidence matrix; figure/table/equation inventory with argumentative roles; separate author-stated limitations from analyst critique; idea gates |
| [nature-skills `nature-paper-xray`](https://github.com/Yuan1z0825/nature-skills/tree/main/skills/nature-paper-xray) | Read body + appendix + footnotes + captions; reconstruct the real path; treat figures as arguments with possible counter-evidence; preserve hedging; state what was actually read |
| [v0lka/skills `note-template.md`](https://github.com/v0lka/skills/blob/main/research/study-paper/assets/note-template.md) | Contribution → evidence matrix with mandatory anchors; method pipeline with inputs/outputs; critical layer with ranked red flags; reproduction checklist |
| [KaleabTessera/Research-Paper-Reading-Template](https://github.com/KaleabTessera/Research-Paper-Reading-Template) | Quick Look; TL;DR; relevance/soundness; future work; relation to own work |

## 2. Design decisions

- **Evidence anchors are mandatory.** A claim without a section/page/figure/table/
  equation anchor is recorded as absent evidence, not as “probably true”.
- **Author vs analyst is explicit.** `[Author]` and `[Analyst]` labels prevent the
  note from turning interpretation into claimed fact.
- **Figures are arguments.** Each main figure/table gets “what it is meant to
  support / what it actually shows / counter-reading / anchor”.
- **Critical layer is required.** At most three ranked red flags; author-stated
  limitations are kept separate.
- **Idea cards are testable.** Each has closest prior art, delta, why now,
  feasibility, a discriminating experiment, and an expected negative result.
- **Reading mode matters.** Skim / Review / Implement / Teach select different
  depths, but the evidence matrix and critical layer are always present.
- **No summary-only output.** If the note is only five bullets, it has failed.

## 3. Recommended reading order for the note

1. Identification and provenance.
2. Problem/motivation and research question.
3. Contributions and evidence matrix.
4. Method reconstruction and experimental design.
5. Key figures/tables.
6. Critical layer.
7. Gaps and idea cards.
8. Reproduction checklist.

## 4. What “good” looks like

A good note lets a future reader answer, without reopening the PDF:

- What exactly did the authors claim?
- What evidence supports each claim, and where is it?
- What is the actual method pipeline, including assumptions?
- Which figure/table is load-bearing, and what would contradict it?
- What are the three biggest weaknesses?
- What is reusable, and what is missing?
- What are 3–5 testable ideas that follow?

If the note cannot answer these, it is not ready to support idea generation.
