# 辅助材料的筛选结论

主能力来自四个参考库。以下是对用户提供截图与旧模板的辅助学习：图表按 metadata 的 13 个图型目录固定种子各抽 6 张，共 78 张缩略图；“精选100”表格实际找到 99 张并查看。不是宣称审完约 9500 张图片，也不是按会议名给质量打分。元数据来自本地 CSV，未独立核验论文与 caption 的准确性。

## 可迁移的结构

| 样本标识（本地文件） | 观察与可用部分 | 使用边界 |
| --- | --- | --- |
| Box & violin / `2201.05574__p9__fig6.webp` | 上方紧凑箱线与下方共享数轴直方图；兼顾分位与尾部 | 合并分布视图是否必要取决于问题；不能只借颜色或从截图制造分布数据 |
| Heatmap / `2507.04147__p9__fig10_s1.webp` | 联合密度加上下/右侧边缘分布，字段单位明确 | 联合与边缘来自同一数据；原例 jet 色标需替换，不作为配色标准 |
| Heatmap / `2501.08292__p6__fig2.webp` | 相关矩阵只保留一个三角、零点发散色标、内嵌系数 | 显示的是排名相关，不应把普通相似度直接叫 Pearson 相关；标注需检查背景对比 |
| Heatmap / `2407.16377__p8__fig6.webp` | 对数成本轴、连续响应、无数据区明确留白 | “No data” 与零概率不同；不等间距坐标不能靠 imshow 假装等间距 |
| Contour / `2505.24832__p7__fig7.webp` | 理论曲线/场与经验观测叠加，用不同标记表达来源 | 理论公式和观测都需有来源；不是让模型拟合出好看的地形 |
| Histogram / `2503.00151__p21__figD.1.webp` | 同一批数据从分布与分位两个层面看 | 评估是否增加推断信息，避免为补齐四宫格重复同一结论 |
| 表 014 / `2207.11919__p6__tabI` | 精度一致、均值与 SD 同格、少量横线、克制强调 | 误差定义来自 caption；最大均值不等于显著优于其他方法 |
| 表 015 / `2211.03089__p4__tab2` | 组件勾选与指标同表，清楚展示消融组合 | 缺少组件不自动意味着处理相同、可以直接比较，需读实验设计 |
| 表 018 / `2302.04675__p9__tabV` | 数据集分组 + 消融行 + 指标列，减少重复标签 | 保留组级表头与含义，不需要复制密集字体 |
| 表 032 / `2301.10545__p9__tab8` | 两种任务下的指标被跨列表头组织 | 各列方向独立声明；不可把不同任务分数混排求平均 |
| 表 089 / `2411.11745__p4__tabII` | 模型家族表头、逐列方向、分层行，适合异尺度指标 | 多个近似最优的展示不替代不确定性与检验 |
| 表 093 / `2510.14557__p10__tab4` | 表格紧接对应图形，数字与趋势各司其职 | 二者须用同一单位和归一化基准，不能让图与表互相矛盾 |

上述选择只保留结构上的优点。裁切、彩虹色图、过重网格、双轴、没有说明的误差、过多颜色、低分辨率和不必要三维都在素材中存在，不能照搬。素材分类也不是可靠图型真值：有些 “Confusion matrix” 条目实际上是别的图，应实际查看。

## 旧代码的具体取舍

四份旧教学脚本及本地截图未确立再分发许可，公开包不保留原文件。可迁移的结构经验保留；新示例见 `assets/examples/visual-review/`，数据和生成器均随包提供。

- **043 分块热图+注释**：采用 row/column split、顶部分类带、独立符号轨道和轻边框的结构。原值是随机演示，不借其“基因”名称制造实验。
- **038 聚类热图+注释**：保留树与矩阵同步重排、注释绑定的机制。随机 p 布尔矩阵要删；44 种模块颜色与大量星号不作为审美标准。
- **033 个性化森林图**：采用分组背景、点区间与零参考线的联合组织。原随机星号、颜色过多和右缘文字拥挤要修，不把随机区间当效应估计。
- **058 分面折线+区间**：借鉴不同预测区间/模拟区间的并列表达与分面标题。必须解释两种区间的定义，不能擅自互换；脆弱 gtable 位置修改不作为默认实现。

这些内容的本地来源与文件哈希在 sources.json；它们没有清晰的统一可再发布许可，保持为用户授权工作材料，不擅自替其补写开源许可证。
