## 关键行为

依赖未完成、输入/输出漂移、来源消失、后继替代旧结果时不会作为可开始候选，失效沿依赖传播。任务完成需实际文件并覆盖计划交付，且记录宿主做过的核对；取消必做工作不算交付。失败/重做保留新身份，替代必做任务仍承担责任；用户改变范围则新目标并保留旧历史。

重复请求保持幂等，旧修订不能覆盖新计划，批量验证失败不提交，原子替换失败保留旧状态，视图失败会说明业务状态已提交。批量换目标并关闭目标的回放也有回归覆盖，防止后续状态误改此前事件。dry-run 不写项目；读取检查不改业务历史。

running 不会自动成为重跑候选；blocked 恢复/运行取消需记录查证依据。hold 不假装停止进程，仍允许记录已有运行的真实结果。未知预算只限制相应执行任务，不阻碍独立诊断。路径越界、私密配置、Workflow 自证和 Windows junction 被拒绝；项目身份不匹配被拒绝，相对引用支持项目搬移。

四项集成实际调用现有工具：目录工具可分配空 Workflow 让原生 init 使用，并限制唯一入口；已有总览在 register/refresh 后保留；真实 analysis ingest 的 draft 作为“仅接入任务”的完成材料，不解释为科学分析完成，修改同一原生文件时 Workflow 与 Memory 都提示复核；review freeze 保留当时稿件，原稿修改不会自动改写旧快照。

修复了一处既有目录测试的可移植性问题：本地化 Windows 命令输出按字节接收，仅在失败提示中容错解码，避免默认系统编码使 junction 测试在断言前崩溃。未改变目录产品行为。

## 尚未由这些检查证明的能力

科学路由、最小判别动作和专业接收标准由宿主模型判断，以上通过率不是科研成功率。`evaluations/scenarios.md` 是 13 个合成情境的待评测规格，不是已运行的模型结果。还需要用真实项目记录实际决策、调用、成本、失败与修正，验证跨会话长期效果。

本版没有后台 runner、自动轮询服务、多代理执行引擎、向量检索或集群适配。文件台账不能保证外部任务恰好执行一次，也不能检查授权摘要、预算文本或科学核对说明的真实性。文件指纹和事件哈希不是可信时间、签名或完整防篡改日志。工具与 Memory/专业工作区没有跨目录原子事务；宿主在恢复时分别查证。
