We prove that, for every finite nonempty set \(A\) and every function \(f:A\to A\) satisfying condition \(C\), there exists an element \(a\in A\) such that \(f(a)=a\). The proof relies on both finiteness and condition \(C\). A supplied counterexample shows that the corresponding assertion for all infinite sets is false, even when \(C\) holds. This boundary limits the theorem’s scope and identifies the question for an extension: under what additional assumptions can fixed-point existence be recovered for infinite sets? It does not rule out existence results within restricted infinite classes. We therefore conjecture that, for every nonempty infinite set \(A\) in the class \(K\) satisfying the additional compactness assumption \(D\), every function \(f:A\to A\) satisfying \(C\) has a fixed point. This restricted assertion remains unproved.
