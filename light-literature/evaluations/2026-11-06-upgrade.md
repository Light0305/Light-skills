# 2026-11-06 文献技能升级记录

版本：0.11.0 → 0.12.0。目标是让项目文献工作在身份、来源、阅读范围和下游交接上可靠，同时保留单点请求的轻量使用方式。源码目录名 `light-literature` 与历史入口名 `literature-search` 保持不变。

本轮完成源码、入口、提示、交接文档和有关检查。这里记录已执行范围；真实宿主全篇精读、领域检索召回和整个科研网络的实际效果仍待单独验证。

## 基线与实际问题

修改前 49 项离线测试全部通过。新增针对实际缺口的回归可复现以下问题，说明原有测试没有覆盖这些边界。

| 问题及后果 | 本轮处理 | 有关验证 |
|---|---|---|
| 只有相同姓氏或缺作者，也可能按标题误合并；无 DOI 记录能桥接不同 DOI | 弱匹配要求可靠年份、较完整作者与可辨标题；冲突 DOI 阻止合并；候选关系单列 | `test_identity_regressions.py` |
| 预印本/正式稿不同 DOI 被当一份报告，可能混用文本/结果；历史别名丢失 | 保留不同报告身份和已有 versions；强标识相同也不能抹掉不同 DOI | `test_identity_regressions.py`、`test_dedupe.py` |
| 保留的稀疏记录共用 fallback paper_id | 稳定内容后缀区分并记录碰撞 | `test_identity_regressions.py` |
| 增量引文归并不统一标识，后来补充的标识未索引；提前丢弃重复来源记录，部分引用边悬空 | 统一标识、索引补充身份、对全部来源映射并重写两端，区分获取数与实际新增数 | `test_identity_regressions.py`、前向/后向实际扩展管线的 `test_citation_intake.py` |
| Crossref 单篇路由错误带上 collection 的 select，实际返回 400，影响 DOI 补全与参考文献追溯 | 只有 collection search 发送 select，单篇路由取完整返回 | `test_crossref.py` 与公开 API 实测 |
| 增补文章后 manifest 只剩最新批次，Idea 优先读该索引时看不见旧文章 | 保存全库 entries 和 library_total，另列 selected_paper_ids；命令返回 entries 继续表示本批 | `test_literature.py` 与 `test_library_check.py` 中实际调用兄弟 Idea 导入 |
| 同身份传入不同 PDF 会替换原文，旧笔记却仍存在；丢失旧 PDF 后也可能错误恢复 | 记录 SHA-256，在选中文献准备前核对既有/传入/记录字节，冲突停止，保留旧阅读产物 | `test_literature.py` |
| PDF 创建日期被推作发表年份；文件存在容易被误当阅读验收 | 发表年缺证据则未知；新增只读完整性检查，阅读产物标记 present_unverified | `test_library_check.py` |
| 短/缺摘要在配置阈值时被自动排除；通用评分提示被当统一纳排标准 | 短摘要保留待核对；按实际纳排条件判断；评分只作辅助；校验明显矛盾的决策/理由 | `test_screening.py`；提示语义尚待宿主情境验证 |

## 使用与协作调整

- 入口由 567 行整理为 72 行，详细检索操作迁到 `references/search-workflow.md`。单点检索、领域地图、片段/全文阅读、引文字段/支持核查和续读分路。
- 新一轮研究先读有关 Memory 和原始材料；已使用 Workflow 时核对当前任务和输入版本。独立局部任务不强制安装或初始化 Memory / Leader。
- 交给 Idea / Leader 的内容包含身份、版本、定位证据、实际完成范围和未决项。重要决定和失效变化按需交给 Memory，原文与完整检索记录保留在 Literature。
- 补充 `references/identity-and-integrity.md`，明确记录/报告/研究层次、全库与本批口径、指纹的局限，以及同 DOI 来源变更当前需要显式保留旧版迁移，尚无自动迁移命令。
- 去除入口和采集交接中的过期机器绝对路径，核对实际 crawl 的 `new-case` / `probe` 接口；默认归档到 Acquisition 并链接回文章。
- 对当前 OpenAlex 访问说明和 Crossref 路由进行核对。旧版来源健康记录仍以其原日期标注，未宣称本轮查询了每个平台。

## 后续宿主和整体情境

以下为待验证情境，不计入已通过项：

| 情境 | 观察重点 |
|---|---|
| 只问某个公式或一页内容 | 直接解释所问范围、引用实际锚点，不强制生成整篇读本 |
| 一篇有图表和附录的真实论文 | 实际视觉阅读、原文/译文锚点、图表/公式一致性、缺失内容诚实标注 |
| 围绕一个领域形成文献地图 | 概念和来源覆盖、反例、实际纳排理由及停止规则；不能用测试数证明召回 |
| 数据不充分、阴性/理论/定性文献 | 判断适配研究类型；不按抽象总分、发表声望或正面结论决定纳排 |
| 既有记忆冲突或 PDF 版本变动 | 回来源核对，保留旧版依据，给 Idea / Leader / Memory 正确交接 |
| 研究循环或论文返修后定向补查 | 复用原库，只补当前缺口，保持旧轮次与采用版本可追溯 |
