# light-diagram 总入口集成记录

2026-10-31。新增根目录 [总 SKILL](../../SKILL.md)、[工具选择与交接规则](../../references/routing-and-handoff.md)、交接校验脚本及 UI 元数据。四个子 skill 增加了可选的共同交接入口，保留独立使用方式。

## 之前与现在

之前是四个独立 skill：prompt 只产提示词，三种后端读取图像和各自 scene。此前生图、核查与工具交接由助手在聊天中手动完成，没有根 skill，也没有共同状态索引。

现在总入口负责读取用户内容、建立科学 brief、调用 prompt skill、实际调用生图服务、核查参考、按需求选择一个主要后端，并回收验证证据。已有参考可跳过提示词/生图，明确 prompt-only 或 image-only 可以提前完成。用户指定工具优先，未指定时按编辑需求和可用能力选择。

这是助手执行的统一 skill 工作流；不是一个可以无人值守读图、生成和重建的端到端程序。校验脚本只检查状态与证据一致性，不调用模型或桌面应用。

- 3 个既有实测案例的交接。

另检查根 skill 与四个子 skill 的 frontmatter、入口链接和本轮脚本语法。这些检查不证明生成质量或跨学科成功率。
