# 复杂架构和机制图的复现检查

先写关系清单，再测量图形。一个倾斜网格往往含顶面、前面、侧面和格线，多对象数量不能当作网络层数。区分逻辑边与多段连接符，明确连接的可见模块及层级。

对多尺度模型逐级检查 `Z1…Zn` 的归属，禁止把表示同一状态的模块侧端口和平面误读成两份计算。跨级总线、绕开模块的支路、方向反转及相邻箭头重叠，需要对照论文/作者实现确认。放大模块中的同名端口应与总图一致。

残差不能仅凭“从下方绕到上方”来判断：记录分叉发生在 Conv 前还是 Conv 后、合流是加法还是乘法、门控乘回的是哪个中间量。科学修正页应列明具体删边、改方向和重连来源，复现页可保留源错误供比较。

从像素转换成形状时，优先修复以下容易被自动检查漏掉的问题：

- 斜视平面的连接点取可见边上的坐标，而非包围框中点。归一化点需要随尺寸缩放的原生公式。
- 箭头大小与线宽分开检查。默认最小箭头在复杂图上会近乎不可见，文件结构仍可通过。
- A_p、Z1、X0 等采用可编辑文字范围设置下标，核对 PDF/PNG 中的实际位置；字体/字号正确不代表下标正确。
- 细小渐变、纹理、照片和半透明叠加难以逐像素一致时标明近似范围，避免用“100% 还原”描述。
- 连接符的包围框可能与标签框相交，而线段不接触实际字形。布局告警需要导出目视判断，不能一律忽略或一律视为遮挡。
- 一条折线拆成多个原生线段时，仅首段有起点箭头，仅末段有终点箭头，拐点保持透明且不算科学节点。

实际 PowerPoint 重开后，对源端和目标端均测试随动。不要只看 `BeginConnected/EndConnected`，还要检查其连接的是正确节点并测量移动量。临时移动后丢弃测试改动，重新打开已保存候选，避免将浮点漂移写进最终版。

当前默认验证每个有关系的场景节点，其中可能包括透明路径端点，不代表组件分组、缩放、旋转、自动正交避障、跨平台导入均通过。用户需要整体搬动一组图元时，应实际分组并重新验证关系，不能承诺透明拐点会自动跟随未分组的组件。

新增分支后，旧节点可能缺少新端口。增量插入只会跳过同名对象，不会同步其自定义连接点。必须显式替换或更新涉及的节点，再重连；连接点数不一致时应保留失败记录并修复，不能仅移动线条让它看似接住。锂硫电池案例即通过保存重开检查发现并修复此问题。

多个退化后果不能为排版方便串成因果链。例如锂硫电池中的穿梭相关活性物质损失和界面钝化，应按依据表达为并行或经寄生反应的分支，不能直接画成“锂损失导致钝化”。若错误原本写在提示词里，应承认是提示词设计问题，保存修订提示词并区分是否实际重新生图。
