## 基线与实际缺陷

默认 Python 缺少可选 Scrapling，初始 67 项中有依赖导致的失败/导入错误；未以安装或跳过掩盖。包内已有 .venv 具备依赖和浏览器，运行 69 项基线，发现版本探测在命令无任何输出时发生 IndexError，其他测试通过。

新增第一批 12 项定向用例，修复前为 10 失败、2 错误：重复捕获/同名附件覆盖旧原件，raw capture 修改未被校验，目录附件无封存、路径越界、坏 case 结构崩溃、重复证据 ID、空响应无哈希、case probe/capture 未在发流量前检查已记录范围、仅凭 VERIFIED 标签宣称验证完成、旧 site 输出被复用。另有 4 项输出用例先复现 CSV 多行误计数、坏 JSONL 被算作记录、无输出/非法输出仍返回采集通过。新交接/执行机制复核时又用两个先失败用例补上导出科研说明被修改、指针回退掩盖最新失败的问题。

## 已完成的改动

1. **原始采集留版**：每次捕获有独立 fixtures/captures/CAP-* 目录，正文/请求/元数据登记 bytes/hash，证据引用具体原件；顶层 fixtures 只保留兼容工作副本。记录截断、状态及 HTTP/browser 表示；空正文仍有哈希。重复探测/改路由留哈希历史，并能在原 case 继续，不倒退进度。
2. **完整性与旧格式**：目录附件有清单/tree hash，同名新内容不覆盖旧档；坏结构和非法路径返回明确失败；捕获证据本身与 raw/meta 对账，不能只删登记隐藏变动。case target 与 target.json 漂移被发现。旧未封存目录/缺执行记录保留警告，不补写历史认证。
3. **真实验证记录**：verify 默认只读核查；--run-check 明确执行选定的可信本地 Python 检查，留输入指纹、退出码、日志及不可覆盖的历史 receipt。变动、超时或失败会使当前验证失效；指针不能回退到旧通过记录掩盖最新失败。阶段标签本身不证明验证。learn 需要当前有效检查；使用审阅后的工作样例，不复制 raw capture 档案。
4. **科研数据交接**：可选 dataset export/check 保存用途、研究/诊断意图、筛选单位与范围、字段/单位/缺失语义、覆盖/重复/失败说明，以及显式选定文件和来源。派生链回连实际 raw 与 code、命令/环境且无环；不复制大型数据。捕获来源不得错配，已知截断/错误响应只能作诊断。导出本身登记到源 case，连研究说明也受版本核对；旧导出不覆盖，新捕获不使无变化的旧导出自动失效。
5. **运行输出核对**：site run 拒绝复用已有输出；缺失/非法输出判为失败。JSONL 核对实际对象记录，CSV 用真实解析器计数，修复多行字段误计；空 Scrapling 版本输出不再崩溃。case 网络入口落实已记录的访问范围，非布尔授权值不被真值转换放行。
6. **科研网络与记忆**：按真实数据缺口进入，优先已有数据/下载/API，不强塞单向流程。补充 Data → Design/Experiment/Analysis 的原生交接和修订影响，Memory 恢复后仍核对专业原件，并交回真实增量及 Workflow 状态。SKILL/CLI/证据/兼容说明与目录规范已同步；前置元信息改为受支持的 metadata。

## 明确边界

- 所有科研/运行验证材料在临时隔离目录，未采集真实用户科研数据。本轮没有真实公共站点采集、真实领域课题或独立宿主模型行为评测；这些仍待整包阶段。
- 文件哈希、事件和 receipt 是本地一致性记录，不是防篡改认证、可信时间或外部来源真实性证明；检查脚本的断言质量与科学解释仍需复核。未封存所有隐式代码依赖/环境、未穷尽网站页数或数据真实性。
- dataset spec 的覆盖数量、缺失、研究单位和使用条件是需核实的记录，不因格式通过就被科学认证；已知错误/截断例外之外，不能自动识别每种 200 错误页、选择偏差或泄漏。
- 源 case 不可访问时，dataset checker 明确警告只能检查保留文件，不能认证当前来源或完整导出登记。路径迁移须核对后新建交接；旧格式缺失的事实不追认。
- 头部过滤不是正文/URL/日志/截图脱敏；分享前仍须审阅。receipt 超时控制直接执行程序，不承诺结束任意后代进程、网络请求或控制浏览器总内存。
- Memory/Workflow 与科学依赖由宿主按实际材料反馈；不存在后台常驻总控、通用 invoke_skill API 或自动科研验收。
