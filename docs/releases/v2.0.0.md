# Light-Science v2.0.0

Light-skills 更名为 **Light-Science**。本版围绕一篇论文或一项软著组织科研项目，也可关联同源专利等成果；研究循环、论文制作与按需扩展由实际问题连接。

## 主要变化

- 15 个主要技能与 4 个 Diagram 子入口，覆盖文献、想法、设计、实验、分析、采集、选刊、写作、数据图、方法图、评审、专利与软著，以及项目记忆和协调。
- `Memory/` 保存有来源的上下文和决策。Leader 读取相关记忆，再回专业原件核对，选择下一步并维护需要的 `Workflow/`。
- 统一产物位置、版本与交接。研究证据和原生文件仍由各阶段管理，未决问题、失败和修改理由保留。
- light-write 使用当前 0.3.0：用户模板优先，完整稿件默认 LaTeX 与实际编译检查后的 PDF。
- Chart 0.11.0 使用自行实现的审图记录工具和像素诊断、19 篇自写指南及 10 组可复现合成示例。公开包不依赖或分发 FigMirror 原始文件；像素诊断不输出科研质量总分。
- 软著按当前工作流交付功能说明、软件代码、软件说明书三份 DOCX。
- 新 Logo、米白 Q 版工作网络、可在 GitHub 渲染的 Mermaid、九张数据图与三工具原生重建展示。方法图分别为 Illustrator 锂硫电池、PowerPoint CRISPR–Cas9、Visio MonoFormer。

整包 2.0.0 是发行版本；各技能保留自己的版本号与既有调用名，包括 `literature-search` 和 `light-anaysis`。

## 安装与升级

```bash
npx skills@latest add Light0305/Light-Science
npx skills@latest add https://github.com/Light0305/Light-Science/tree/master/light-chart/skills/light-chart
```

Windows 可使用 `npx.cmd`。实测根目录发现 14 个入口；Chart 通过第二条命令补充。Diagram 总入口包含四个子目录，也支持按子目录独立安装。详细位置、依赖和调用见[安装说明](../installation.md)。

v2 使用根目录 `light-*` 布局，替代 v1 的 `skills/` 与旧安装脚本；原 Git 历史和 v1.0.0 Release 保留。安装完整技能目录并确认实际版本，避免旧副本覆盖新版本。

## 发行内容与许可

原创部分延续 MIT。第三方代码、参考图和示例数据保留各自条款，包括非商业使用限制，**整包资源不统一视为 MIT**。许可缺失的原始文件不随包分发；部分文献图只保留原始链接与阅读卡片。具体见[第三方说明](../../THIRD_PARTY_NOTICES.md)。
