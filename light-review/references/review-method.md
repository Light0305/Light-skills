# 评审方法：先重建论证，再检验

## 1. 从完成稿接入

记录稿件标题/ID、版本、文章类型、评审范围、材料清单、目标读者及精确 venue（如有）。区分“作者没有提供”和“论文没有报告”。只给摘要时可审主张强度、逻辑及必须询问的事实，不能评价完整方法、全部图表或录用机会。

最终 PDF 与源文件矛盾时分别记录，不擅自挑一个值。内部评审以用户指定的提交版本为对象；草稿、图表与补充材料版本不配套时优先标记这一风险，独立可完成的核查继续做。只有材料明确过旧且会使工作无效时才停相关判断。

PDF 同时需要可搜索文本和真实页面/图形。采用宿主可用的 PDF/图像读取能力；扫描稿需要 OCR 时，核对承重数字、负号、指数、希腊字母和表头。原文没有行号时用“PDF 第几页 + 节名 + 段首/图表编号”，不要编行号。Markdown/LaTeX 可加源文件行号，但注明不是 PDF 行号。

## 2. 首遍的中性重建

先用简短文字回答：研究究竟解决什么问题、相对哪个现有做法、核心改变是什么、怎样验证、真正展示了什么、在哪些条件下成立。指出值得保留的贡献、设计或结果。若不能准确重建，先回看论文；不能用模板批评掩盖没读懂。

暂存疑点及其出处，直到完成相关上下文核验。先确定证据类型，再决定需要的验证方式：实验、观测、仿真、证明、文献综合或解释性论证。不要预设每篇论文必须提供实验和 p 值。

## 3. 承重主张—证据对应

只追踪影响贡献成立的主张，不逐句建表。建议结构：

| claim_id | 原文主张与位置 | 支持材料位置 | 适用对象/条件 | 评估 | 尚缺什么 |
|---|---|---|---|---|---|
| C1 | 可复查的准确转述 | 表、图、方法、推导或引用 | 样本、任务、时间、假设 | supported / limited / unsupported / contradicted / not_assessable | 具体输入或解释 |

- `unsupported` 只表示当前主张没有足够支持，不证明其为假。
- `contradicted` 需要明确相反证据，不能用“没报告”替代。
- `limited` 指存在支持，但范围、比较条件或精度只允许较窄结论。
- 标题/摘要的强版本与正文的弱版本应分别定位，不能只用正文限定语替摘要辩护。

对每项承重主张问：观察是否足够？推理是否成立？是否存在足以改变结论的替代解释？哪项控制/推导/对照真正区分这些解释？若最小修复是缩小主张，直接提出；若会使论文主要贡献消失，明确这是实质性改动，不能说只是措辞优化。

## 4. 疑点的反查

对每个 major/critical 候选问题：

1. 重新读取原文和相邻内容，核对是否准确理解了研究目标及主张。
2. 查全文、补充材料与引用定义，记录查了哪里。没有读到不能写成没有。
3. 尝试合理的替代解释，例如不同分母、加权方式、纳入集或版本，检查是否被明确报告且足以解释差异。
4. 区分观察与推断。“未见独立测试集说明”是可核对观察；“必然存在泄漏”是需要额外证据的判断。
5. 保留仍成立的最窄批评；被原文排除的疑点删除或在复核中关闭。尚不能判断的保留为具体待核事项。

定向复查比“请补充更多实验”有价值。每个必要新增实验都须指出：针对哪个承重主张、排除哪种解释、为何已有材料和更轻量的修改不足。不要规定跨领域通用的种子数、样本数、显著性阈值或近两年引用比例。

## 5. 评审自身的质量检查

定稿前检查：

- 技术批评是否含足以复查的位置、事实和适用标准？引用是否真的支持这条批评？
- 是否把方法未写清当成方法已做错，把数据不可得当成作者没数据？
- 是否遗漏与怀疑相反的结果、限制或补充说明？
- 是否用不可比论文的更高指标证明作者方法差？
- 重要问题是否去重并保留多个证据位置，而非拆成多条营造严重性？
- 建议是否真正解决问题，是否会引入新混杂、数据泄漏或事后选择？
- 是否夸大图片异常、误判统计意义、误称复现成功或伪造专家共识？
- 即使作者不赞成结论，这条意见是否仍能靠证据与论证独立成立？

措辞专业直接。对话长度、严厉语气、否定比例、相似度分数及作者满意度都不能作为评审正确性的替代指标。

## 6. 综合与可执行排序

先列会改变研究解释的问题，再列局部呈现。报告结论要能追溯到问题 ID、缺失检查或已关闭证据；不先决定“应拒”再补理由。若几个问题源于同一错误纳入集，可组织为一个根因和多个受影响位置。

修复计划分清：必须做、可通过缩小主张替代、可选增强。优先处理阻塞根因，其次必要说明与图文传播更新，最后可选样式。估计成本仅给粗粒度判断并注明假设，不虚构实验工期或已有计算资源。

完整科学审查也可能有局限，例如未检查原始数据或不能独立验证某个证明。说明这些限制具体影响什么判断，不能以通用免责声明代替已有证据所支持的结论。
