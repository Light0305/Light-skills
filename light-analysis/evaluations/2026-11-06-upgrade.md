# light-anaysis 0.2.0 升级与验证

日期：2026-11-06。范围是 D:/Light-Skills 中的源包；保留既有拼写与原生文件格式，不改全局安装、旧研究目录或用户研究结果。

## 基线与问题复现

启用本地 Experiment/Design 路径后，原有 35 项 Analysis 测试全部通过，无跳过。检查中新增 13 个定向用例，在修复前得到 12 个失败和 1 个中间求和溢出错误；后来为重复 claim 身份和选刊路由新增的两个用例也先复现了失败。另补 8 个正向/边界用例，最终共 23 个新用例，不以数量代替科学能力评价。

实际缺口包括：成功退出但 QC 不通过仍可支持主张；失败结局理由可绕过输入漂移；接入时未对原始文件和封存记录对账；QC 内容、更正链、最新记录删除和后续撤销没有完整传播；配置可被当运行证据、主张与实验不匹配、两个证据引用字段可混填；导出后改报告/派生命令仍被视作同一交接。有限大数求平均和相反极端分位点插值也可能发生可避免的中间溢出。

## 完成的修改

1. **有范围的原生接入**：对存在的 run manifest 复核所列运行元数据和本轮显式选择的 outputs/logs；验证 QC receipt 内容、run、supersedes 及已有事件，缺失最新判定不能回退旧通过。原始大文件仍按需登记，不悄悄扫描全部输出或代码快照。旧的不完整记录可以诊断/描述，不获得新的验收认证。
2. **发现与证据关系**：成功运行用于支持/反驳需具备可验证通过 QC、所核对封存子集、原始值或登记派生链，并与该实验主张匹配。外部数据仍可 standalone 分析。已结束失败/超时且被任务定义为结局的合理用法保留，不能用于豁免成功运行输入污染或未完成状态。旧超时测试改用实际原始输入而非 campaign 配置，保留原科学语义。
3. **当前判定及前置依赖**：对正式引用的运行与传递前置运行检查 QC；当前撤销/损坏使有关结论校验失败，仍通过但 receipt 改变提示阅读更正。可访问性和冻结历史分别说明，不改原始运行或旧分析。
4. **交接版本**：新 handoff.sources 绑定 context、receipt、analysis、分析计划/lock、报告和全部 artifact 登记；派生输出与代码按各登记继续验证。导出后改报告/命令登记或增删登记会过期。旧 handoff 明确兼容警告，实质更正使用新 AN/parent。
5. **数值边界**：平均值中间求和溢出时用精确比率均值回退，分位点改用加权插值，保留原科学方法、随机设置和适用范围。
6. **实际科研网络**：增加 light-journal-select 路由，选刊无须虚构新实验预测；补齐恢复 Memory 后核对原生材料、分析更正的下游影响、交回 Memory/Workflow 的真实增量。既有分析方法/领域指南及历史模型试用材料保留，本轮不冒称重新运行了模型行为评测。

## 边界与尚未验证的部分

- 子集封存核对不是完整运行 verify；不检查未列出的全部输出、隐式代码依赖、远程版本或原始数据真实性。
- 本地哈希/锁不是防篡改认证或可信预注册时间；命令登记不证明它实际执行。locator 和结论仍需读取、计算与科学复核。
- 当前 QC 和传递关系只适用于实际引入并引用的原生运行；外部材料、图稿与 Memory 的科学依赖仍由宿主按明确来源维护。
- 旧无 termination_confirmed 记录不自动成为已确认终止；旧格式缺少的检查保持警告/待核对，不改写历史认证。
- 尚未完成真实领域项目、独立宿主模型本轮行为评测以及整包最终综合验收；测试通过不等于统计适用、因果解释或研究路由已经证明正确。
