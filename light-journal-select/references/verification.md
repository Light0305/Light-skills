# 当前事实核验

先核查会淘汰候选或改变首投的事实，再补可选信息。不为装饰表格收集所有指标。以下来源入口在 2026-11-02 检查过相关页面；入口不是未来核查成功的证明，使用时打开适用记录。

## 事实—来源对应

| 事实 | 优先来源 | 不能替代它的证据 |
|---|---|---|
| 身份、官网、出版者、更名 | 正式出版者/学会网站，ISSN记录，DOI落地页相互对照 | 名称相似的搜索结果、邮件中的投稿链接 |
| 范围、文章类型、字数与投稿阶段规则 | 该刊当前 scope、author instructions、文章类型页面 | 同出版社别的刊、几年前模板、已出版文章长度 |
| WoS具体索引及当前状态 | [Master Journal List](https://mjl.clarivate.com/)，适用的官方变更记录 | 有 JIF、出版者声称“WoS”、旧文章已被检索 |
| JIF/JCR类别与分区 | [Journal Citation Reports](https://jcr.clarivate.com/) 的适用年份记录 | SJR、CiteScore、中科院分区、未说明年份的转载 |
| Scopus当前覆盖 | [Scopus Sources](https://www.scopus.com/sources)、[官方内容政策与停收说明](https://www.elsevier.com/products/scopus/content/content-policy-and-selection) | 历史文章仍在库、SJR页面存在、期刊网站旧标识 |
| MEDLINE、PMC、PubMed关系 | [NLM Catalog](https://www.ncbi.nlm.nih.gov/nlmcatalog/) 的具体期刊记录与[NLM/PubMed说明](https://pubmed.ncbi.nlm.nih.gov/about/) | 一篇文章有 PMID/PMCID就称整刊被MEDLINE收录 |
| OA目录与出版信息 | [DOAJ](https://doaj.org/) 中的对应ISSN记录；再查官网 | 不在DOAJ就断言不合法；把DOAJ当SCI名单 |
| 费用、减免、机构协议、许可 | 该刊/出版者费用表、适用类型和路线、单位图书馆协议、资助方原始政策 | 泛化“OA刊都收费”“订阅刊全免费”、口碑报价 |
| 资助方OA兼容性 | 资助方当前条款、[Journal Checker Tool](https://journalcheckertool.org/)及适用协议 | 仅知道机构名称就假设可以免费OA |
| 中文/地区/学科目录 | 目录发布机构、当前正式名单与单位适用规定 | 第三方“核心”标识、与本次考核不一致的旧版名单 |
| 近期发表内容 | 期刊档案、文章原文/摘要、DOI记录、可靠学科数据库 | 搜索摘要、预印本、相似期刊的文章 |
| 审稿时效、历史录用率 | 官方有口径与统计期的数据；经验来源只作补充 | 论坛个例、广告、无分母和时期的百分数 |

同一个来源不一定能证明所有字段。例如期刊官网适合证明作者指南，但其收录声明最好到收录方核对；Crossref可核元数据，不证明当前收录、期刊质量或研究结论。

## 每个决定性事实的最小证据记录

```text
事实/要求：……
对象与适用范围：正式刊名 / ISSN / 文章类型 / 出版路线
值与口径：……；未知则明确未知
来源：精确URL或作者提供文件的位置
来源类型：官方期刊 / 官方索引 / 官方政策 / 原始论文 / 元数据 / 作者材料 / 二手资料
访问日期：实际核查日期；材料本身另有发布日期/数据年份
证据状态：已核实 / 作者提供未外核 / 推断 / 未核实
限制或冲突：……
```

“已核实”表示确实检查过适用来源的内容，不是有一个链接就完成核验。无需保存长篇受版权保护的网页全文；保留足以回查的定位与自己的简短释义。

## 收录与指标：必须拆开

- **有JIF ≠ SCIE。** Clarivate 已把 JIF 扩展到包括 ESCI、AHCI 的核心合集期刊；核查精确索引，不从指标反推。[官方变更说明](https://ir.clarivate.com/news-events/press-releases/news-details/2022/Clarivate-announces-changes-to-the-2023-Journal-Citation-Reports-All-Web-of-Science-Core-Collection-journals-including-arts-and-humanities-will-have-Journal-Impact-Factors/default.aspx)
- **历史在库 ≠ 当前持续收录。** 对 Scopus/WoS检查状态、覆盖年份、停收/暂停及更名对应关系。承诺将来被收录不是当前满足要求。
- **JCR Q1、SJR Q1、CiteScore百分位、中科院分区不是同一值。** 报告指标名、数据年/版本、类别；多类别按作者要求选用并披露差异，不能择最高分区掩盖相关类别。
- 区分**发布年份**与**指标数据年**。网页在某年更新，不代表所有数值都是该年指标。不能凭当前月份猜“最新IF”，不能把 OpenAlex 的均值指标叫 Clarivate JIF。
- 同一发布版还可能更正。2026-11-06读取的 [JCR官方2026更新记录](https://journalcitationreports.zendesk.com/hc/en-gb/articles/47808147130129-2026) 显示2026版提供2025数据，并列有2026-10-14重载更正。决定性指标需保留发布版/数据年/类别与适用更正记录，不能因为年份相同就沿用更正前数值。本例不是未来“最新版本”的永久声明。
- PubMed是检索资源，MEDLINE是其中的重要组成，PMC是全文档案。基金资助的单篇入库和整刊遴选不相同；按单位具体措辞核查。[NLM说明](https://pubmed.ncbi.nlm.nih.gov/about/)
- 期刊级指标可以是现实约束，不是单篇质量或录用概率的代理。[DORA声明](https://sfdora.org/read/)

### 中国情境：分区与单位要求

中国科学院文献情报中心于 **2026-03-27** 声明，自2026年起不再更新与发布期刊分区表，其他机构的分区表与该中心无关。[原始声明](https://las.cas.cn/news/tzgg/202603/t20260327_8178738.html)

因此，在该声明仍适用时：

1. 不声称存在“该中心发布的2026最新中科院分区”；他方评级要写清发布者和体系。
2. 历史分区写明版本、年份、大类/小类及TOP等具体属性；未查到就标待核。
3. 作者要求“中科院一区”时，使用已有单位规定；若版本/替代规则不明，只问这个关键缺口，其他匹配研究继续。
4. 旧帮助页面、网站页脚年份、第三方转载不能覆盖更新的官方声明；将来若有政策变化重新核查，不把本文件当永久在线状态。
5. 单位预警/不认可名单、全国性预警与收录方停收是不同事件。核对发布者、版本、适用单位和期刊身份，避免把一个年份的关注信号写成永久定性。

## 费用与OA路线

把候选表示为“期刊 + 文章类型 + 出版路线”，而不是每刊只有一个价格。

- 分开记录 mandatory submission/page/overlength/color fees、必选APC和可选OA费用；只在适用的项目计入总成本。
- Hybrid的订阅路线可能无APC，但不自动满足即时OA/许可要求，亦不保证无其他费用。
- Diamond OA可不收作者费；Gold OA不能直接推断有费或无费。查该刊实际政策。
- 区分“标价”“协议覆盖”“已确认减免”“可申请但未批”。机构、通讯作者、资助方、文章类型和发表日期等资格未确认时，不能按零费用通过预算门槛。
- 核对价格采用哪个时间点。不同出版者可能按投稿或接收时生效价格计费；例如2026-11-06读取的 [PLOS费用政策](https://plos.org/fees/) 说明按投稿日适用价格，不能泛化到其他出版者。混合网页抽取若丢失“刊名—文章类型—价格”的对应关系，不按显示顺序猜价格。
- 同币种比较；换汇时记录汇率来源和日期，并考虑税费、强制附加费与预算边界。区间跨越预算上限时标 `unknown`，而不是取最低价通过。
- 无法确定实际路线的强制费用：硬预算标待核；如果只是费用偏好，则保留候选并说明不确定性。

## 时效与截止节点

拆分投稿→首轮决定（可能含desk reject）、投稿→外审后决定、投稿→接收、接收→在线发表、正式刊期及索引入库。官网数字用原指标名和统计期，不能换名。

官方中位数也可能有筛选口径、样本时期和发表者幸存偏差。发表论文的received/accepted日期仅反映已接收样本，不能据此推断总体等待或录用率。经验平台如LetPub、SciRev可显示另一侧信息，但有自选、记忆和样本量问题，不能作为保证。

若毕业要求在某日拿接收函，只有“首轮7天”仍不足以确认可赶上。给出时间风险、可压缩的作者修订环节和改投节点；没有适当数据时明确“无法证实期限可满足”，不虚构精确时间表。

官方历史录用率若确有数据，可按年份、文章范围、分母报告为背景。它既不是该稿概率，也不能与语义相似度相乘得到概率。

## 身份与期刊风险

采用可描述的具体信号，参考 [Think. Check. Submit.](https://thinkchecksubmit.org/journals/) 与 [EIFL 2024指南](https://www.eifl.net/system/files/resources/202409/choosing-a-journal.pdf)：

- 从出版者/学会和ISSN记录交叉定位官网，用实际文章/DOI与档案比对；仅匹配ISSN不足以排除冒名站。
- 查适用的同行评审、编辑责任、费用、投诉/更正/撤稿、许可与保存政策；必要时核对编辑身份、COPE/OASPA等成员声明。
- 保证接收、保证极短外审、伪造指标、冒名编辑/域名、隐瞒强制费用等是需要说明的具体风险。
- 收录、COPE成员、DOAJ记录或高指标都不是绝对质量担保；缺少某项成员资格也不能单独证明不可信。不要按整个出版商、国家、语言、OA模式或单一网帖定性。
- 明确身份欺诈或已确认不符合硬性不认可名单时排除；可疑但未证实写“待核：具体冲突”，不要无证据指称欺诈。
- “本次检查范围内未发现某信号”不等于“安全无风险”。列明哪些检查无法完成。

## 失败、冲突和更新

官方页面不可读时可换官方作者指南、出版者文档或合法可用的数据库；一至两种合理替代仍不能确认，就记录阻塞字段，继续其他候选。付费/机构访问用已有授权，不要求用户交出账号凭据，也不绕过访问限制。

冲突先查ISSN、日期、文章类型、出版路线和适用作者资格。官网与聚合网站不同，通常取适用的当前官方内容；同等级权威来源冲突时保留两条、标未知，不能悄悄选有利值。

正式写作启动、转投、投稿前，或用户约束、文章类型、期刊身份/出版路线、费用/目录版本变化时，重核受影响字段。没有统一的“30天内都有效”；动态信息的访问日期必须可追溯。
