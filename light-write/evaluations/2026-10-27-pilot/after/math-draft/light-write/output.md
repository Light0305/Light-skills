We study fixed-point existence for functions satisfying condition C. We prove that, for every finite nonempty set A and every function f:A→A satisfying C, there exists x∈A such that f(x)=x. The proof uses both finiteness and C, and a counterexample shows that the conclusion can fail for an infinite set even when C holds. This boundary distinguishes the proved result from an unrestricted infinite extension: condition C alone does not guarantee fixed-point existence on arbitrary infinite sets. It therefore motivates asking which additional assumptions permit an infinite analogue. For the restricted infinite class K, we conjecture that, for every nonempty A∈K satisfying the additional compactness assumption D and every function f:A→A satisfying C, there exists x∈A with f(x)=x. This conjecture remains unproved; it identifies a proposed extension under additional assumptions while keeping its logical status distinct from the finite theorem.
