# 创新差异核查与文献驱动的修改

## 核查的对象

把候选拆成：研究问题、对象/条件、机制/方法、关键假设、评价、预期知识贡献。最近工作不一定共享标题或技术名；同时找“同一问题换了术语”和“同一机制用在别处”。

这里的“创新性查重”是研究内容与最近工作的比较，不是文本重复率检测，也不是专利法律意见。

## 检索路线

按领域使用可用的原始文献来源，例如 PubMed/Europe PMC、Crossref、OpenAlex、arXiv、学科会议论文集、出版商页面。普通网页搜索可发现线索，关键判断回到论文或官方项目页。先复用上游筛选和引用图，缺哪种证据补哪种，不为了满足来源数量重复检索。

| 意图 | 检索构造 | 希望推翻的假设 |
|---|---|---|
| `duplicate` 直接重合 | 对象 + 任务/问题 + 方法的同义表述；搜索贡献句中的关键关系 | 这个问题尚未被同样解决 |
| `mechanism` 机制重合 | 抽象机制/约束 + 预测或过程，去掉领域和产品名再查 | 这不是已知机制换包装 |
| `adjacent` 邻域 | 对应概念的学科术语 + 结构/过程 | 外领域不存在可直接覆盖的解 |
| `skeptic` 反方 | 方法/主张 + failure、negative results、replication、critique 等适用词 | 关键前提可靠且收益真实 |
| `citation` 引用扩展 | 最近工作的参考文献、后续引用、修订版本、勘误 | 固定种子集覆盖了当前进展 |

查直接重合与至少一种不同概念路径，而不是把同一个短语丢给两个搜索框。检索量按撞库风险、用户要求和证据缺口调整；无法访问全文或数据库时，保留结论的条件性。

每次真实检索记 `search_id`、当前 idea ID/版本、日期、来源、原始 query、意图、状态、命中的真实 `paper_id`、筛查范围和限制。结果为零也要说明实际检查了什么；工具超时、429、登录墙分别记录，不能转写成无结果。

新增来源的题名、作者、年份、DOI/链接要在原始记录核对。发表与预印本版本保留各自报告身份；不同 DOI 不自动合并，关联需核对显式版本关系及实际差异。同一研究的多个报告也不当作独立研究重复计数。网页发表时间、论文首次投稿时间和本轮检索时间不要混为一谈。

## 最近工作对照

为入围方向选真正最接近的工作，而不是最有名、最容易打败的工作。数量取决于不同重合维度是否被覆盖。

| 论文/正文锚点 | 已解决的问题/条件 | 与候选重合处 | 未覆盖的具体差异 | 差异的知识价值 | 判断置信度 |
|---|---|---|---|---|---|

最近工作核查至少能回答：

- 如果把对方的主方法忠实实现，我们的主要结论是否已经是它的直接推论？
- 差异是技术构造、识别方式、机制、问题边界、可测量能力，还是仅换了实例？
- 如果 baseline 也实现同样的工程改进或增加同样的资源，差异还在吗？
- 哪条决定性事实已经在正文核对？哪条仍只来自摘要或作者说法？

可以有价值的差异不必都属于“新方法”；可信复制、识别旧结论的失效条件和测量纠偏都可以是贡献。必须准确表述其类型。

## 允许的判断状态

| 状态 | 可以说什么 |
|---|---|
| `unsearched` | 这是待查重的构思 |
| `inconclusive` | 已查的范围尚不足以判断，列出具体缺口 |
| `overlap_found` | 找到重合，指出工作和被覆盖的部分 |
| `differentiated_within_scope` | 在所记录的来源、日期和检索路径内，存在以下具体差异；仍可能遗漏 |

最后一种状态不是“已证实全球首创”。不把模型熟悉度、嵌入距离或自评分转成创新认证，不用“尚无人研究”替代有边界的比较。

## 修改后重新查

用一个简短的修改记录保存：`version / previous_version / trigger_paper_ids / changed_facets / reason / searches_to_refresh`。

查重对应当时的科学内容指纹，证据对应核对过的来源版本；字段和旧记录迁移见 [修订与交接](revisions-and-handoffs.md)。无意漏升版本时，内容检查也应提示复核，不能只依赖手写 version。

找到覆盖主贡献的文献时，先明确覆盖事实，再选择停止、收缩问题、改变机制或改为边界/复制贡献。若替代方案只是把碰撞部分换个名，仍判为重合。

一次实质 pivot 后：

1. 重写一句问题和贡献，确认不是纯措辞变化。
2. 重新检查各部分的一致性：新问题是否仍由旧方法回答？原指标还能验证新贡献吗？
3. 使相关论文集合随修改更新。旧检索留作历史，当前版本不能借用不相关的旧查重通过状态。
4. 若仍无可辨识的差异，保留淘汰/暂缓原因，不继续无限包装。

预算用尽或新增检索不再改变当前比较时可以停止，但结论必须带上停止理由和未覆盖范围。一个真正能改变选择的新来源出现时再恢复核查。
