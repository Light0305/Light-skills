# 根据参考图适配

实际查看原图，先说明它要解决的问题与用户希望借鉴的部分。分别提取面板职责、标记/构造、坐标与单位、图例/色标、文字层级和留白；不要直接复制原数值、像素位置或未知误差。

将这些设计映射到本任务真实数据。保留原始标识、缺测、分母与不确定性定义；缺少区间或检验时不补造。新数据与参考构造不适配时，说明调整并采用更合适的表达。

先导出当前 PNG 与实际 PDF，再通过 [review-cycle](review-cycle.md) 的 reference-fit 模式审阅。参考图必须声明 design_reference，前稿不能冒充外部已发表图。组合坐标和标框规则见 [comparison](visual-review/comparison.md)。

修订从当前采用版本出发，保持正确数据与必要构造。记录真实意见、修改理由和最终采用文件。视觉接近不证明科学正确，也不是版权许可；引用和再利用仍按来源条款处理。
