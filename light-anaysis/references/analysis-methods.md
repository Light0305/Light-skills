# 分析方法：先确定目标量和结构

## 快速选择

| 问题/数据结构 | 合适的起点 | 需要额外检查 |
|---|---|---|
| 两个独立条件的原尺度均值差 | 均值差与适当区间；模型适用时用 Welch 方法 | 真独立性、厚尾/极端值、样本不平衡；秩检验通常不等于均值差检验 |
| 同一单位上的两个条件 | 单位内差异、配对区间/模型/有效随机化检验 | 配对真实性、缺对与顺序效应；不能因 seed 数字相同就配对 |
| 多因素、协变量、重复/聚类 | 对应层级的回归、混合模型、GEE、聚类/设计型推断 | 分配单位、可识别性、随机效应/簇数、模型收敛及小样本方法 |
| 二分类/计数/比例 | 原始分母、风险差/比/odds 或合适 GLM | 零事件、过度离散、暴露时间、单位间依赖；odds ratio 不是 risk ratio |
| 同一批对象的预测比较 | 对应损失/预测的配对比较 | 固定已训练模型还是整个学习过程；对 AUROC/F1 等整体指标需重算指标 |
| 时间、空间、轨迹、删失 | 保持相关结构的模型、block 方法或生存/删失分析 | 漂移、非平稳、删失机制、边界条件；不能 iid bootstrap 每个点 |
| 多任务/数据集×重复 | 逐任务效应 + 明确任务权重的分层/多层汇总 | 固定任务集合与新任务总体不同；任务数、seed 数分别报告 |
| 确定性数值解/证明/反例 | 误差分解、收敛、解析/认证参考、假设和构造核验 | 近似误差与随机误差分开；有限搜索不证明普遍不存在 |

这是方法入口，不是“见到某种格式就自动选检验”的菜单。先沿用合理原计划；不合理时保存原分析并解释修订及证据地位。

## 数据与有效性

保留逐单位数据和数据字典。映射 `input → parser → unit table → contrast/model → table/figure → finding`，中间转换保留代码、参数与行数变化。明确一行代表什么、主键是什么、技术重复如何进入独立单位。

先看按组/批次/时间的计数、分布和缺失。异常值可提示录入、饱和、仪器或真实尾部；IQR/MAD 阈值只提供标记，不自动删除。排除要有实际原因、作用范围、是否预先规定、接触结果时间与影响；主分析之外保留包含/排除的合理敏感性。

不把 missing、invalid、timeout、censored、below detection 和 true zero 混用。失败与方法强相关时，仅分析成功运行会造成选择偏倚；报告成功率及条件性能，按目标量选择 composite outcome、删失或适当敏感性，不能随便把所有失败代成最差观测值。

缺失处理依赖目标量、设计与机制：报告原因和组间差异；完整案例法、插补和加权各有假设。学习型插补/变换不能拟合到测试集；MNAR 等无法由已观测数据排除的机制做有意义的敏感性，不声称“检验通过所以随机缺失”。

## 不确定性不是一个统一误差条

先说明随机机制、目标量、条件化对象和目标范围，再选估计区间。常见误读：

- SD 描述散布，SEM 描述某些条件下均值精度，CI 是给定程序的区间；不能互换。
- 固定模型对测试样本 bootstrap，不能代表重新训练和超参数搜索的波动。
- 共享训练集的 k-fold 分数相关，不能用 `SD(folds)/sqrt(k)` 当通用泛化误差 SEM。
- 只变初始化 seed 的区间不覆盖数据采样、任务变化、选择最佳配置的偏差。
- 聚类 bootstrap 重采独立簇并保留内部结构；多层数据要说明哪些层是固定/随机，不能默认层层重采总是正确。
- 重采样次数 B 控制数值近似，不增加原始独立 N；小 N、离散、退化或重尾时 percentile/BCa 都可能失效。

频率区间报告置信水平、构造、重采层级/次数/种子与适用假设；Bayesian 分析报告观测模型、先验、后验估计、可信区间、收敛/采样诊断与先验敏感性。R-hat、ESS、发散及 posterior predictive checks 用来找问题，单个阈值通过不证明模型正确。LOO 等模型比较对应预测目标，不自动证明因果或机制。

## 检验、多重性和选择

明确比较族：主要/次要终点、方法×任务、子组、消融、时间点及观察次数。按目的选择预定 FWER（如 Holm）或 FDR（如满足适用依赖条件的 BH）等方法，并保留原始与调整结果。只对最终挑中的几个比较校正无法修复隐藏的搜索。没有使用检验时解释估计和决策方式，不强加 p 值。

置换/随机化检验需要与实际分配、区组及可交换性匹配；配对 sign-flip 也不是不需假设。不能只因非正态就置换全部行。双侧改成单侧需预先依据；观察反复偷看和择时停止使用匹配的序贯方法，不能事后用普通固定样本 p 值认证。

查看多次分析/模型/提示时记录分支。探索有价值，但标签不应随结果改变。选出最优模型后，在同一测试集上重新给普通区间会遗漏选择偏差；需要独立验证、合理 nested 过程或适用的选择后推断。文献最佳结果和自己某个种子的最大值不构成公平对比。

## 阴性、等效和实际意义

把估计与有依据的实质界值放在同一原尺度。解释界值是事前、继承还是事后提出；事后界值可做探索敏感性，不能充当预设成功标准。

| 区间/证据所容许的范围 | 可以说什么 |
|---|---|
| 同时容许有意义改善和有意义损害 | 信息不足，不能声称无效或方向确定 |
| 排除所声称的有意义改善，但未满足双向等效 | 可限定地排除该幅度的改善，未证明两者等效 |
| 在适用推断下落入预设等效区间 | 支持该界值、该对象与条件下的实质等效 |
| 统计上非零而幅度在可忽略范围 | 统计可检出与实际不重要可以同时成立 |

TOST 在显著水平 α 下使用对应的 `100×(1−2α)%` 双侧区间进行等效判定（需满足所用方法假设）；普通差异检验的 95% CI 不要不加说明地充作所有等效检验的判定区间。非劣界值有方向且需独立论证；不能看完数据再扩大界值。

BF 比较明确定义的模型及先验；后验落入 ROPE 的概率、BF、p 值与效应区间不是同一种证据。不能为阴性结果随意换到“更有利”的统计框架。前瞻补样规划比较多种合理效应/方差情景；不追跑到显著。

## 稳健性、机制与失败分析

以可能改变结论的选择为轴：数据排除/缺失、量纲变换、模型结构、协变量、权重、任务集合、精度与评价器。先限定科学可辩护的规格，再完整报告关键分支；统计上跑得通的所有模型不都是合理备选。只有估计目标一致的规格才适合直接汇总。

比较方法的预算/数据/参数量/推理成本应对应要声称的优势。组件消融同时改变容量或优化时，把“效果变化”与“机制解释”分开；交互通过直接对比/模型检验，不能从一显著一不显著推断。

为每个竞争解释写：预测、现有证据、会推翻它的观察、当前识别缺口。下一步优先解决最可能改变路由且成本可控的缺口。数学、仿真和定性论证也需要反例/替代解释，只是证据形式不同。

## 可选的配对效应工具

`scripts/paired_effect.py` 只处理 `unit_id,a,b` 三列 CSV：每行是一个已由宿主确认相互独立的、完整配对单位。同一任务下真正独立的配对重复可以使用；同一受试者的多时点、共享训练集的 folds、混在一起的任务×种子不能直接使用。

工具计算均值改善和 **iid 配对单位 percentile bootstrap** 区间；不自动认定配对/独立性、不算 p 值/等效、不推断机制。至少两个单位只是算法的最低输入要求，绝不表示样本充分。常数差导致区间退化时明确警告；小 N 或重尾时由宿主选择更合适推断。大规模/复杂结构用合适科学库和项目代码，不强用这个工具。
